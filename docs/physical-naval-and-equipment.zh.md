# 物理甲板、船炮与装备

船体使用 Blender 制作并烘焙 32 个方向的船体、上层遮挡和独立武器图。行驶、开火不会摇晃整艘船；只有炮管后坐。乘员是地图上的真实单位，甲板由船体几何、障碍和单位脚印决定容量，同时校验总质量。

## 航行与射界

转向参数按弧度/秒设定，UI 转换为度/秒。载重、偏载和船舵损坏降低转向速度，船帆损坏降低推进能力；帆完全损坏时不能航行，舵完全损坏时不能转向。转动的扫掠船体不能穿过海岸。普通单位不增加船体转向限制。

| 船型 | 空载转向 | 船首炮位 | 舷側炮位 | 出厂价格与配炮 |
| --- | ---: | ---: | ---: | --- |
| 轻舟 | 36°/秒 | 1 | 0 | 120 金，无附送火炮，保留弓箭攻击 |
| 运输船 | 22°/秒 | 1 | 0 | 160 金，空炮位 |
| 战船 | 18°/秒 | 1 | 左右各 2 | 170 金船体 + 220 金火炮 = 390 金 |
| 轰击船 | 13°/秒 | 1 | 左右各 1 | 240 金船体 + 330 金臼炮 = 570 金 |
| 喷火舰 | 26°/秒 | 1 | 左右各 1 | 190 金船体 + 180 金喷火器 = 370 金 |
| 大型舰 | 12°/秒 | 1 | 左右各 3 | 280 金，空炮位 |

船首炮只能在前方 ±30° 内射击，舷炮只能在对应侧面 ±35° 内射击。攻击指令选择能投入最多可用火炮的一侧并缓慢转向；保持位置的船不会自动转船追击射界外目标。每门炮分别瞄准、冷却和承受损伤。安装炮位需要附近己方人员，炮位不能被单位挡住，还要满足船型兼容和载重。

船坞以相同价格制造可流通的武器：火炮 220 金、臼炮 330 金、喷火器 180 金。出厂炮、拆下炮和再次安装的炮始终是同一物品；读档不会重复附送。现有商店没有物品回售，未来回售也必须以同一物品价格和折损核算。

火炮直射在首个命中点产生半径 48 的范围伤害，对空船体造成 2 倍伤害；击中船员时，对承载船体附带 1.25 倍的伤害。臼炮范围 75，对空船体 1.7 倍、船员承载船体 1.5 倍。一次爆炸击中多名船员，只对同一船体结算一份附带伤害；船员优先于船体接受攻击。弓箭、近战和法术分别使用较低的附带损伤。乘员不享受船体提供的远程减伤，运输船上的乘员伤害为 50%。

## 甲板通行、占领和修理

船与船、船与岸接触且脚下连续可支撑时，单位可按正常移速步行跨越；隔着水缝不能跳过去。桅杆、舱室、炮位和其它单位都阻挡通行。没有己方或盟军乘员，且只有一个敌方阵营占据甲板时，船直接转移所有权。击杀者、在途炮弹和掉落装备仍保留各自原来的归属。

闲置的己方甲板农民自动花费金币修船；明确的其它命令优先。修理先恢复完全失效的帆和舵，再处理船体与剩余部件。农民也可从相邻友船步行过来救援失去推进能力的船。船坞修理同样包含部件和已装武器。

船体不显示悬浮血条，选中后在底部面板查看船体生命；船员沿用普通单位的血条。装备窗口显示帆、舵和各门武器的耐久。

## 人物与船舱

人物有头、身体、腿和脚四个穿戴位置，另有**手持与背挂共用的四个携行位置**，没有背包。主副手只是这四个位置中的持用引用，不增加容量。制式武器也占一个真实位置。双手武器占双手并收起盾牌，但盾仍占携行位置。

| 物品 | 穿戴或携行位置 |
| --- | --- |
| 火焰披风、皮甲 | 身体；收起时占一个携行位 |
| 疾行靴 | 脚部 |
| 回春头环（原回春戒指存档键保留） | 头部 |
| 护腿 | 腿部 |
| 圆盾 | 一个携行位，持于副手生效 |
| 双手剑、风暴法杖 | 一个携行位，持用时占双手 |
| 闪电杖、卷轴、书、爆破包、袖珍塔 | 一个携行位；消耗品用完恢复先前持用武器 |
| 船炮、臼炮、喷火器 | 搬运时占满四个携行位；船舱占连续四格；安装后占一个兼容炮位 |

重型船武器会降低搬运者移动速度并扩大搬运脚印。船舱和已安装武器的质量都计入载重。收在船舱或携行位的穿戴物不提供加成；衣甲和手持盾提供的是人物装备减伤，与船体无关。

装备窗口左侧为人物穿戴、当前持用和四个携行位，右侧为炮位、部件和船舱。拖拽指定位置，双击向另一侧转移，单击查看持用、穿戴、安装或使用操作。容量、兼容、距离和人员条件失败时给出反馈，失败操作不改变物品状态。

商店只新增皮甲、护腿、圆盾和双手剑四种基础装备，原有掉落和商品沿用明确的位置规则。旧存档只迁移一次：超出容量的物品放到原持有人旁边；新存档直接恢复，不重复发武器或重排位置。

## 界面呈现

装备窗、战斗 HUD、地图框、提示框和菜单共用木纹、磨损黄铜和内凹皮革材质。人物使用完整单位模型，空槽显示对应装备轮廓；主副手与携行容量分开呈现，基础属性集中在人物下方。船只状态、左右舷炮位和船舱分区，四格重物保持连续展示。界面保留键盘焦点、拖拽来源和滚动位置，小屏时人物与船舱纵向排列。模型资源完成加载后会刷新已有头像，避免长期保留低精度占位图。
