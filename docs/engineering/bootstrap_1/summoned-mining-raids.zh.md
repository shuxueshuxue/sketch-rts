# 闲置精灵的独立矿线任务

整支军队因敌军响应压力保持阵地时，召唤出的精灵也会原地耗尽寿命。现在只有处于待命且没有刷野或基地入侵任务时，精灵才独立攻击未受塔覆盖的敌方工人，永久召唤师继续留在原指挥链。三条现代路线共用这项能力，不识别敌方策略版本，不争抢友军矿线。

目标按实际地面转向道路和地形行进时间排序，剩余寿命须覆盖行程与按原伤害规则计算的击杀时间；道路和目标排除塔、野怪覆盖。敌军若能直接射击召唤师，或能在其下一次召唤前沿地面道路抵达，就保留精灵屏障。指挥官与收尾分队不把已派出的精灵再次算进可用军队。零新增持久状态、原价原属性原思考频率、没有兼容或默认路径。

22 个实际 SDK 场景包括三路线、两阵营、镜像方向的普通施法与真实击杀，覆盖过期寿命、道路绕行、盟友、塔、已有作战任务以及下一次召唤前到达的敌军。12 个正例均真实击杀矿工，永久宿主与金币无损。精确公共 #354 对同样场景 10 通过、12 失败；最终相关检查 184 通过。

初版只检查精灵行程和寿命。在同一真实 24000→26400 tick 残局中，下达 68 次袭矿命令仍没有杀到工人，并让基地更早失守，因此未发布。加入按原施法冷却检查的宿主屏障后，同一窗口只派出一次；双方永久损失仍为 12，期末均保留一座基地，没有工人击杀或胜者。这是避免初版退步的证据，不是全局强度提高或正式验收通过。
