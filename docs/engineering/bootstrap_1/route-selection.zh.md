# bootstrap_1：道路选择与装载距离

父版：`0e8dbacfc1c47fe117e4d08a8b73fcbda6a3cf74`。

伤兵原先按直线距离挑治疗建筑：山墙另一侧的井近在眼前，实际路程却远于同侧治疗点。新增 `nearestByRoute` 复用地形距离场，明确指定 land／sea，只让可达目标参与比较，保留输入顺序的同距结果。船坞选基地、岸防选工人和候选伤兵选治疗点共用这个函数，删除 naval 的私有实现。威胁覆盖及攻击范围继续按直线距离计算。这个度量只包含地形道路，不声称计算建筑绕行、人体净空或风场中的航行时间；这些由移动层处理。

装载原先要求运输船中心距出发点不超过 100。正常 Sapphire Archipelago 保存点的中心距离约 116，船体边缘距装载点只有 19.801：它满足游戏已有的工人体半径＋BOARDING_GAP，却反复取消运输。装载改用现有船体几何和原登船范围，不新增距离参数。工人绕船坞时，甲板局部寻路还会过早接管；现在必须完整人体已经适合该连接地面，地面寻路才交接给甲板。没有 SDK 绕过、新 AI 状态、缓存、兵种属性、资源或地图分支。

- 41 项道路选择、伤兵与岸边接近检查通过。十二个三路线／两族／镜像山墙场景中，伤兵受三枚正常弩炮技能的 108 伤害，选择同侧较短道路，60 秒内恢复满血，500 金零支出。四个两族／镜像倾斜船坞场景的两个原工人实际登船、满血存活，金币与正常维修费用守恒。
- 对相同测试输入加载精确父版的三个改动模块，上述十六个新增修复场景全失败；没有临时改写工作区源文件。
- 27 个历史公开 AI 指令帧、79 条指令及其内存与父版完全相同。工程分支冻结 revision `dba796cfc152379adad9988a1314f94ffc736137` 的 54 个源码哈希未变。
