# 可安全到达的空矿直接投入基地资金

射手／骑士策略此前为没有敌方覆盖的已清矿先攒防御塔。资金只够 400 金基地时，这个前置要求阻止扩张；已有收入时还会多花 125 金。现在无敌方覆盖且至少一名工人的实际道路安全，就直接购买原本的基地。野怪营地、友军矿和敌方覆盖仍按现有选择规则处理；所有工人道路受威胁时保持不建设。召唤师原本就能直接开发这样的空矿，本批保留这一行为。

复用原有矿距、合法建设位置、普通基地目标与实际建筑障碍道路、威胁范围；两个运行时模块 +15／−2，没有新增数值门槛或持久状态字段，没有地图／种子条件或资源加成。

236 项不同相关 SDK 检查通过，Node 20 构建通过。48 个新增案例覆盖资金不足以同时买塔、双种族、镜像、友军与敌塔占据、较近但危险的工人道路，以及全部道路受威胁。危险道路案例以普通建设命令走完 1,800 tick，基地完成、工人保持满血、零损失。原公共源码在这 48 项中通过 24、失败 24。已有实际开矿／采集／上交、资金守恒、殖民地与矿防检查保持；两组原空矿测试改为明确要求不购买多余防御塔。

一个当前规则 2 的 GrandEstuary 无对手窗口，恢复同一 9,600 tick 世界、AI 记忆和 ID 后，第三座基地下单从 12,705 提前至 12,345，提前 18 秒。双方最终均为三座基地、三处收入矿和 16 名工人；仍各有五名主力死于野怪。这个结果只说明空矿投资等待减少，不能证明整体战斗收益，更不计正式对手验收。

原 CPU 门槛和发布检查保留，新增建设／道路检查同时进入 CI 与生产流程。完整证据见[回执](./free-expansion.receipt.json)。下一步继续处理走散的工程兵／施法单位穿越计划外营地，而不是重新运行完整矩阵。
