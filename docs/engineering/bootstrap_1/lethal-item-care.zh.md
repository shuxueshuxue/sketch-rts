# 物品致死风险与已有治疗站

当永久士兵的血量仍高于原 35% 伤兵门槛，却不足以承受敌军携带物品的下一次初始冲击时，原指挥不会将它交给已有的安全治疗站。本次从原生装备、冷却和物品规则读取雷电棒／风暴杖的初始冲击，在一个既有思考周期的相对移动范围内，按当前单位防护计算风险；与原伤兵条件并列。实际治疗站和完整道路仍经过原可达、威胁覆盖与治疗距离检查，没有新增路径、状态、阈值或医疗数值。

12 个原生 SDK 场景覆盖三策略、两种族、两方向：原版均失败，候选可以躲开冲击、完成满血恢复，零新增伤害、阵亡与支出，然后归还普通行军。冷却、守护、友军、远距和背包中未装备物品分别保留正常行军。既有治疗、道路与地面效果检查继续保留。

在真实 Reedwater 5400→9600 原生同世界观察中，收窄的治疗准入版本与父版的所有已记录世界、记忆、命中和采购相同，末 16 名永久非工人、两基地、11 工人、1 次野怪死亡；它没有消除该完整道路不安全时的阵亡。这一观察发生在补充“物品必须实际装备”的限定之前，不能改标签当作最终源码完整验收。

曾尝试无治疗路时临时逃离、扩大普通武器预测、提前领取守矿队伤兵等组合。虽然局部规则测试可通过，真实同世界窗口把一名枪骑兵救活后又使其他士兵死亡，野怪损失从 1 增到 2。这些组合未发布，补丁保存在临时实验记录；没有把一次被双重计数污染的零损失结果当强度证据。后续应针对慢速前排的掩护、实际清野任务与无计划接触的集体处理继续做因果观察。
