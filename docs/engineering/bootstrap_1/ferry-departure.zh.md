# bootstrap_1：登陆部队腾出运输船离岸通道

完成返航任务后，真实岛屿开发中的运输船仍不能去港口：两名闲置的登陆士兵挡住船体扫过的离岸路径。按普通 SDK 移动命令移开这两名士兵，同一条船即可离岸；没有修改船体碰撞或单位数值。

运输船维修任务现在同时安排接触船体的健康、永久、闲置陆军移向可达的己方基地。接触使用实际船体边缘距离；目的地按安全道路到达时间选择。海军在腾路期间保留这些单位的任务，继续已有的避战移动目标。工人、战斗命令、伤兵和骑射分队不被征用，敌方火力覆盖的道路不被选中。

36 个新 SDK 场景覆盖三个 v9、两族和镜像地形：12 个离岸及正常付费修船场景、12 个已有任务保护场景、12 个危险道路拒绝场景。新实现 36/36，父实现 24/36；连同既有恢复、海军、物品和治疗检查，共 370 项通过。TypeScript/Vite 构建通过。

同一完整 27000 tick 无对手 sapphireArchipelago 开发存档及策略记忆重放至 30000：父实现停在原岸边；候选自行腾路、到港修满并于 28560 开始下一趟岛矿运输。所有原有永久单位仍在，正常金币规则不变。

继续观察到 33000，工人和护卫已经登陆下一岛，但第五基地仍未开工；其他殖民地补兵目标持续占用海军经济目标，仍需处理。该段不是全图竞速完成、无损刷野完成或正式 1v2 验收。既有 CPU 门槛问题尚未解决。
