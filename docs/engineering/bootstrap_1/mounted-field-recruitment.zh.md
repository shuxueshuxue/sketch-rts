# 独立骑射的招募入口

此前新骑射任务能打暴露近战，但招募只接受野怪与矿线。现抽出共同的目标选择，实兵与马厩出口的未升级原生兵种估算共用相同道路、敌我关系和火力覆盖规则。只为速度更慢、威胁射程更短的目标请求原有一名骑射；数量、优先级、价格、研究与思考频率原样。

48 项原生 SDK 检查通过，包括旧矿线与清营24项，以及三路线、镜像、暴露／覆盖／远程／友军24项新检查。六个暴露目标场景按正常初始500金与真实采矿购买一名骑射，击杀近战追兵，零受伤、零永久损失，金币守恒。主队的已购屏障固定在自己的前线，属于生产和独立任务的局部证明，没有把它当全控制器胜局。公开父版本对完全同一新测试18通过、6失败，失败场景均未购买骑射。另79项骑射、医疗、刷野和矿线交接检查通过，Node20完整构建退出0。

实际 Pineshade 骑士败局在12000和18000帧的敌军离工厂更远，且站位与道路已经受到覆盖，本入口仍不准入。没有缩放道路门槛或绕过敌方火力来适配这场败局；它仍需独立检查主队与经济。完整1620格与未见种子尚未验收。
