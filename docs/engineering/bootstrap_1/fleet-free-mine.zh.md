# 空矿远征与海路距离

真实单机海岛状态中，运输船已有两名工人、两名步兵和三名召唤师，却一直等待攻不下的大陆矿。删除缓存后重新计算仍选同一目标：旧排序把守军战力乘 500 再加到原主基地的直线距离上，可航达的三座无守军矿被近处龙群压过。这不是无法航行；暂停 AI 后下普通卸载命令，船能正常前往空矿，船与乘客没有新增损伤。

将岛矿选择提为 `chooseNavalMine`：先比较矿边的实际敌方、野怪和防御建筑威胁，再用已有 `nearestByRoute` / `walkingDistance` 比较船队及己方可达港岸到登陆点的海路。候选港岸必须和登陆点连通。海路长度不代表考虑风向、加速、转向及船体的航行时间。己方已有基地、敌方占矿基地和友军矿仍由原有资格规则排除。

沿用 20 秒规划间隔重新评估未出航的目标。装载中的殖民远征可以换到新目标，保留乘客和出发岸，并重新开始任务进展计时。已经出航的殖民船保留目标，避免在海上反复掉头。没有新增持久记忆字段、版本特殊分支或地图 / 种子分支。

36 个真实 SDK 场景覆盖三种 v9、两族、镜像、友军空矿保护和已出航任务的稳定性。同样场景在父版本 `e55e17d` 中 12 项通过、24 项换矿失败；候选全部通过。12 个额外海路场景以陆地屏障证明直线较远、实际航路较短的矿胜出。相关海军、护航、返航、清障、岛上基地检查共同验证。
