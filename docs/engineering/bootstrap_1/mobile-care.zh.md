# 独立伤兵与现有牧师会合

主大陆的独立骑射手受伤后仍被骚扰脚本持续指挥；牧师追赶患者，患者却没有同步向牧师会合。现在复用现有远征医疗的患者分配与会合命令，由移动救治在独立任务之前领取患者。没有威胁时跟随已有牧师，有威胁时使用既有撤离微操。指挥器不再把这些患者计入进攻兵力；牧师仍由原医疗模块治疗。恢复到原阈值后继续原独立任务。

远征医疗的逻辑原样抽成两个共享函数。舰队预留、营地医疗、治疗站患者和自疗牧师继续由原流程负责；不新增医疗状态，不修改资源、单位数值、思考频率、冻结策略或游戏规则。运行时涉及四个模块，其中新模块 29 行，没有兼容路径或默认补值。

148 项 SDK 检查通过，覆盖登陆伤兵、无牧师远征、前线医疗、真实医疗道路、舰队所有权、跨水骑射手、购物及移动连续性。新增六项全控制器场景覆盖三系列与镜像：患者立即向现有牧师会合，600 tick 内恢复到原阈值、存活、无消耗，并重新接受原骚扰任务。父版本六项全部失败于原独立任务仍抢占患者。Node 20 项目构建日志完整并确认 Vite 构建结束。

同一真实失败骑射手出击的 9000–9300 tick 世界、ID 和全部记忆分别由当前完整控制器继续，两版均两次永久阵亡，骑射手均阵亡。新模块实际发出患者撤离命令，但该窗口没有改善生存结果。本次不宣称正式胜局；完整 1620 格与未见种子验收仍待完成。
