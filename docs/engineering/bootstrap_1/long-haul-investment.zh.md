# 耗尽经济的远矿补工投资

附近矿耗尽后，存活工人会正常搬运远矿；此前补工需求只计基地附近有效矿，所以即使有安全、持续搬运的空矿，两个远矿工人也会独自攒很久才能支付替换基地。

现在在无有效采矿基地、已有真实搬运任务的情况下，以原矿入口间隔、采集量、采集时间、维护费和道路行军时间估算当前与补工后的收益。只有新工人的生产、到矿和回本时间早于攒齐基地的钱时才投资一个工人；排队工人已计入预算。最多补到原矿标准五名，恢复正常基地后由原本的地区补工接手。塔覆盖道路、友军占用、剩余金不足和已攒够基地资本均拒绝投资。资源、价格、单位数值、状态、思考频率和冻结策略不变。
