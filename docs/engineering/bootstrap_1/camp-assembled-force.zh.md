# bootstrap_1：已集结主力与路上增援

父版运行时与 `e9f22b91525f7fd9cc0fdf7d62431296e783476c` 相同。

全图选营地后，正常 Lone Market 主力仍会等待远处新兵和持卷轴的归队者，不能开启下一营地。旧选择器要求整个前排都在其平均位置 450 内；不断训练和远程归队让已集结主力也无法出发。

候选按原 450 集合半径形成局部前排组，以原刷野战力选择最强的一组，再让既有选择器检查这组确实聚拢且足以无损清营。路线、地形道路成本和营地战力都只计算实际选中者。选择结果携带该组，执行器将同一组的 ID 写入既有营地状态；远处增援沿既有流程到集合点，抵达后才加入。邻近查询复用 `withinRangeOf`，不新增阈值、持久状态、地图分支、资源或备用策略。旧选择器仍传入整个前排，旧执行器原样保留。
