## 问题与实现

上一批最终对局 48,000 tick：现金 2,522.42，人口 94/94，唯一经济目标为 `farm`；但最后一次购买在 42,870 tick。原主岛已没有工人。农场选址固定在主基地，施工选择却要求工人能走到那里，因此已有殖民岛的工人无法执行这一目标。
