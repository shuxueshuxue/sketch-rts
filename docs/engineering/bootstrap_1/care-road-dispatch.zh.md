# 伤兵沿道路就医与独立射手调度

伤兵在治疗者射程之外遭追击时，原有局部躲避选择会反复横移，无法沿绕墙道路接近治疗者。正常 Pineshade 射手双敌对局中的首名骑射手因此在 14661 tick 阵亡。

现在区分就医途中和治疗射程内的战斗：射程外沿模拟器实际建筑阻挡道路前进，每次只取一个思考周期的道路前缀；近战单位的身体与接触攻击范围阻挡这段路时，执行原有战斗躲避。射程内沿用原躲避，无威胁时沿用跟随治疗者。短移动终点允许恢复后的单位重新加入原任务，不把前线目的地换成远处治疗者中心。

独立射手此前还受全局刷野模式影响：即使不属于刷野队，微操也被整体关闭。现在删除这两个全局开关，保留脚本栈中刷野队原有的优先领队权。刷野队的射手继续由刷野指挥，其他普通射手、灰烬射手和骑射手可以独立撤离近战追兵。

六个镜像 U 形道路原生场景覆盖三条 v9 路线；另外六个完整射手控制器场景检查独立射手零伤害撤离、实际刷野组不被抢走和零资源支出。父版本在六个相同射手场景中均失败。原岛矿清营、恢复和 24000 tick 完成门槛保持原样；直接走到治疗者中心、没有接触攻击检查的道路前进方案曾破坏岛矿清营，已撤回。

当前公共 #351 的同一 12000 tick 世界、单位 ID 和全部三份控制器记忆，继续到 16000：原版永久阵亡 23 个，候选 5 个；永久战斗单位 12→20，工人 20→21。候选保持同一策略继续到 24000，六个新增阵亡均为工人，永久战斗单位增至 32；再继续至 29221，原生判定 p0 获胜，期间零新增永久阵亡。这是从检查点引入策略的开发胜局，不能计入正式矩阵。独立射手开关单独修改的相同窗口仍为 23 个阵亡，不单独宣称战役强度改善。

普通从零开局的固定候选另行记录。单位数值、资源、价格、思考周期和冻结 d1 策略原样，没有新增持久状态、旧版本兼容入口或缺失数据默认路径。完整 1620 格与未见种子验收仍待完成。
