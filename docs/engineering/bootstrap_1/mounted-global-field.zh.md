# 独立骑射发现全图野战目标

此前只有工厂附近野战目标能触发独立骑射招募。在真实骑士败局一万两千帧存档中，多个比未升级骑射慢、射程短且存在安全射击站位的近战单位，道路距离约1958至2086，却因为工厂周围的局部范围限制被排除。

现在三条Grove路线共享全图野战机会识别：没有可接战的附近目标时，再寻找速度更慢、攻击及技能射程更短的敌军，仍要求完整可接近道路和射击站位。当前接战优先，不为远处目标反复计算全图道路。出发使用现有安全道路的排队移动，进入武器射程或遭遇追击后使用原骑射微操。清营、矿线防守、已有独立任务和恢复仍保留自己的单位。

一处运行文件，零新增持久字段与默认／兼容分支。仍只请求原来的一名150金骑射，原59投资优先级、研发优先级、资源、兵种数值与15帧思考均不变。

110项原生SDK检查与Node20完整构建通过。36项新场景覆盖三路线与镜像：十二个远处／绕塔目标场景以正常500初始金和采矿付费，实际骑射零受伤击杀敌方近战单位，零永久损失、金币守恒；24项塔下、远程、友军、真正封闭河岸控制不招募。固定已有六名步兵保持另一战线，不是正常开局胜局。同一36测试源码的父版本24通过、12失败，全部正例没有购买。

真实旧败局同一12000至16000帧世界和记忆续局，新版出现一名125／125满血骑射，旧版没有；两边都是9名永久损失、16工人、3基地。骑射此时零击杀、零经验。新版最后金币398.17，旧版294.13，但新版总支出少70且少一名骑士和一名轻骑，不能把银行差异当收入增长。没有宣称那场败局已修复；1620格和未见种子仍未验收。
