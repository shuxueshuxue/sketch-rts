## 实现范围

`berth-recovery.ts` 根据真实的殖民返航任务、已登船乘员、原生 landingSpot 和船体覆盖自动识别堵塞，不包含实体 ID 或地图坐标常量。任务记录在 AI memory，依次处理运输船沿船尾方向退让、阻挡船让泊、返泊卸载、空船退出侧向通道和乘员绕行出岸。帮助让路的地面单位仍受既有健康、治疗、作战及任务占用过滤约束。

任务保留相关单位的指令权并拆分保留同组其他单位；禁止新登船招募重新填满正在卸载的任务船。载具或基地丢失、乘员丢失、紧急撤退、新威胁覆盖及超时会释放任务；没有普通替代指令的旧移动/队列会被停止，避免只删除 memory 却让旧路线继续执行。阶段与总时间都有上限和重试冷却。原生地形、身体碰撞、船体碰撞、伤害及对手正常运行。

三路线共用该安全任务，其余路线配置不变。没有修改引擎、美术、性能代码、生产 API 或规则；冻结对手仍从固定历史提交加载。

**对先前诊断文字的纠正：** 公开 `move` 只采用目标点，不采用额外 heading 字段。先前诊断的 heading 是查询时使用的姿态，并未直接控制实际船舵。最终实现只用当前航向计算船尾方向目标，并以同样的普通移动目标进行原生航路查询与执行，不发送未生效的航向参数。实际行走和航行已经再次完整验证。
