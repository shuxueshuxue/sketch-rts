# bootstrap_1：空间索引的已核实前缀与空船舶任务

PR #322 已合并，但生产检查在原 CPU 门槛下失败：裸地图 14080.453 > 12000 ms，ladder 16916.102 > 16000 ms。线上仍是 PR #321 的 `1c62c6f`。本批继续削减实际重复工作；不重跑失败提交或放宽门槛。

空间索引验证在第一个成员、坐标格或队伍变化处停止。前面已经核实的格子与队伍可以在重建时复用；重建继续保留所有当前实体、桶顺序和边界。成员、坐标和队伍元数据按槽位写入，结束时截断到有效长度，避免先清空再逐项追加。旧索引的公开桶保持不变，转移私有元数据时仍使旧索引重新验证。

空船舶任务也有重复分配。船只起始姿态和防御映射是私有的只读空任务视图，由模拟内部复用；有船时仍建立真实逐帧数据。每个游戏保留自己的空登船集合，上一帧集合非空时会清除实际预留。船舶运动、碰撞、登船、船只出生和观察者的既有阶段保持不变。
