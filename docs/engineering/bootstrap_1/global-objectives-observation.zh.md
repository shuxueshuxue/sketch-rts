# bootstrap_1：雇佣营与岛图的实际开局观察

以 #313 运行时、v9_archer / Grove 及正常 500 金、一基地、三工人开始。保留正式图的全部物理席位、地形、矿点、野怪与商店，只移除对手实体，每 15 tick 使用普通完整规划。两次无对手局部观察均不新增正式胜局。

## 古木林

12000 tick 内完成三次普通雇佣：7440、9945、11505 tick 分别购买契约射手；7740 tick 从商店购买守护卷轴。末段三基地、十六工人、十九士兵、三十五野怪剩余。仍损失两枪兵、一祭司，故不能称无死兵清营。

9000 → 10400 续局重现三次死亡。前往弱营集合点的原道路与逐兵检查正常，目标清完后军队改返主基地，其返程经过另一处龙营；救护祭司随后也进入危险区域。新的候选需要检查清营后的退路，而非只检查进营路线。不能因已雇佣和购物就认为这些系统的竞技利用已充分。

## 蓝宝群岛

12000 tick 时一有效矿点、六工人、十三非工人单位（其中一运输船），未清野怪。运输船已自然装上两工人及五护卫，抵岸时仍在卸载命令上。再观察 1200 tick，约 12400 tick 正常完成卸载，说明这不是已证明的登陆死锁。13200 tick 末岛矿基地已开工、击杀两野怪，但已损失一单位。

岛矿确实被开发；全图岛矿覆盖、运输返航效率、无损登陆刷野、伤兵安置与对敌稳定性仍需继续。更早河湾观察图没有雇佣营，不能拿其零雇佣次数推断雇佣系统失效。
