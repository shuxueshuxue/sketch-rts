# 按可达陆地分配骑射任务

骑射手任务分配此前只检查第一名未分配者的陆地：那里没有目标就提前结束，另一座岛上能清野的同伴被漏掉。骚扰编队直接截取全局候选，还会把隔海的单位编入同一个目标；补员只看第一支现有小队，另一片陆地上的小队会被拆出重复任务。

现在逐个`sameGround`连通区域分配，清野和骚扰目标仍复用`nearestByRoute`与`walkingDistance`，每个骚扰编队只招募能走到其目标的同伴，现有队伍分别补员。连通性回答能否步行到达，道路长度回答可达目标之间的远近，攻击覆盖仍使用物理距离。

运行时一个文件+21/-17，净增4行；新增持久字段、调参阈值和地图／种子／对手版本分支均为零。野怪营地每次分配只计算一次，在没有待分配骑射手时仍直接结束。
