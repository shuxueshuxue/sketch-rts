# bootstrap_1：守护卷轴的局部交战与覆盖

守护卷轴此前把全地图本方军队与附近敌人比较，远处的分队会阻止局部劣势阵列提前使用卷轴。多个携带者还会在同一轮向重叠阵列重复施放，并在已有守护仍生效时继续消耗卷轴。

现在在原有 900 距离内比较双方兵力；保留已有接触、远程劣势和最少受益人数条件。当前规划轮使用实际 280 效果半径记录覆盖单位，已有生效守护也计入覆盖。两处独立交战仍可各自施放，没有全局每轮一张的限制。运行时只修改共享物品战术模块，不修改单位、物品数值、资源、永久记忆、决策预算或冻结策略档案，也不增加兼容或 fallback。

49 个真实 SDK 场景覆盖三个 v9、两族、左右镜像、局部优势／劣势、接触／提前施放和两个分开的战团。新实现 49/49；相同 f3ebdc9 父实现 13/49，36 个失败分别暴露错过局部施放或重复消耗。正常敌方射手确实开火；受保护单位在观察窗口没有承伤、没有死亡，第二张卷轴保留。已有守护覆盖时不再重复消费。

连同物品、机械治疗资格、骑射物品、商店、拾取和精英书籍培养，共 121 项检查通过，TypeScript/Vite 构建通过。
