# 骑射应对快追兵时保持连续撤离

撤离点原来正好是一个思考周期的行走距离。引擎在离终点五距离内结束移动，骑射会提前抵达，再花一拍自动寻找目标。一级研究后的面板速度为 99，实际只有约 92.4，低于同级奔袭兵的 95.7。现在撤离距离同时覆盖追兵在下次思考后两拍的行走距离；慢速威胁下原评分步幅保持。单运行时函数 +3／−1，无新状态、采购、属性、资源、地图／对手分支或 SDK 例外。

四个未研究／正常一级研究及镜像原生场景通过。普通 SDK 指令和引擎推进下，骑射按真实速度连续行走三十秒、满血、零受伤；双方普通 500 金，研究费用及银行严格守恒。精确父版四项均失败，其中三场受伤 84，另一场行走距离 2772，低于正常速度应达到的 2970。两批共 58 项不同骑射、营地、道具、冲锋、射手检查通过；Node 20 客户端／服务器生产构建通过，27 历史帧的 79 指令一致，54 冻结源码哈希未变。

共同 Grand Estuary 15600 世界中，原控制骑射在 16201 被击杀；草稿中同一 ID 的骑射存活到 17400，经普通祭司治疗恢复满血，没有重买。它仍受到 84 伤害、只对追兵造成 25 伤害，不能写成无伤击杀。该保存世界来自已撤回的骑士混编采购试验，不计正常开局验收，也不重新引入采购规则。

统一延长评分步幅及只延长移动命令的两个草稿均使原刷野检查退步，已撤回；本版保留慢速营地与冲锋窗口行为。完整 1620 格与最终未见种子尚未完成。依赖未合并 #260、射手撤退及宿主近战反击的本地提交；GitHub 写凭据失效，尚未 PR／合并／部署。
