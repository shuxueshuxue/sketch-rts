# 海岛佣兵按道路归队

原采购、营地访问和雇佣兵归队统一使用建筑列表中第一个完整自有主基地。采购者和新兵处于另一个岛时，原生移动命令只能把他们送到岸边，无法回到当地基地。现在每名采购者及新兵使用共享 `nearestByRoute` 选择陆路可达、道路距离最短的完整自有主基地；发起陆地采购也要求存在可返回的基地。

运行时仅修改 `mercenary-control.ts`，复用已有道路度量。没有新增序列化字段、生产资源、额外思考或特殊地图条件，费用、角色上限、采购优先级与原归队控制沿用现行规则。

十二个原生SDK场景覆盖三条v9路线、两族和镜像：每场从正常500金支付320金，招到两名佣兵；采购者和两名新兵都回到岛上基地180范围内，无单位损失。另两个镜像场景正常支付160金，验证隔水直线更近的基地仍有更长陆路时选择道路更近的基地。完全相同的十四个场景在父版全部失败，新版全部通过。原有购买、返程、任务归属检查合计90项通过，生产构建日志完成客户端及服务端打包。

此项验证只证明有当地完整自有基地时的陆地购买与归队。跨岛运输、缺少基地时的远征和整局胜率仍需继续处理。全部1620格与未见种子未在此候选运行。
