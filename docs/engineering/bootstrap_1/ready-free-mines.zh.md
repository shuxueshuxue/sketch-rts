# 先利用可建设的空矿

无对手的 Grand Estuary 普通开局观察到 12000 tick：两座工作基地、十一名工人、十七名永久战斗单位，零永久损失，另有二十二个未占矿点。经济选了最近的带野怪矿，部队在处理另一处营地，扩张目标被野怪门槛阻止；更远的已清空矿存在十一条可用工人道路，却未被选择。该地图的矿都与出生地陆路连通，此观察不证明岛矿开发。

现在明确传入建设就绪判断：未受野怪占据、有合法基地站位、且未被施工占用的工人能沿已有安全道路到达的矿先排序，然后仍比较道路距离。原领地、敌军力量和盟友占矿过滤保持原样；原指挥器显式使用原道路排序。两个调用处均提供必填函数，没有默认值或兼容分支。矿点判断与普通付费建设目标共用 v6ExpansionPoint，不重复设计一套基地站位。运行时代码三文件 +25/−8，零新增持久状态、原价格属性资源频率。

20 个新增实际 SDK 场景中，三路线／两阵营／镜像方向的十二个场景真正建成较远的清空矿基地并回交第一袋矿，保留近矿野怪，军队和工人无损，支出、现金、携带与矿量守恒。其余检查塔、盟友已采矿、忙碌工人，以及原指挥器道路排序。公共父版本对同样场景 8 通过、12 失败。相关 SDK 最终 214 通过。

同一无对手 12000 tick 的世界、ID 与控制器记忆继续至 16000：原版 3 座基地／3 座工作基地、清野 13；候选 4／3、清野 15。双方均为 16 工人、24 永久战斗单位、零永久损失。候选第三座工作基地在 14000 已工作，原版 15000 仍仅两座，采样证明至少提前 50 秒；候选第四座尚在施工。期末现金 438.18→7.22，体现进一步投资，不宣称总收入或正式对战胜率提高。

完整 1620 格与最终未见种子验收仍待完成。下一步继续在有分离陆地的地图核对岛矿、运输与全图经济。证据、代码哈希及构建状态见同目录 receipt。
