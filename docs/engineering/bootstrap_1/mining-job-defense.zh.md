# 保护实际长途收入，并按接触时间安排撤离

矿点附近的基地被毁或枯竭后，仍在工作的长途矿工不属于原统帅的基地防御目标。原代码同时会为了未支付、尚未施工的未来基地持续待机。现在有本地采矿基地、可支付的基地资金、已下施工命令或正在施工时保留原护送；断粮且没有建设承诺时允许继续原攻击选择。实际远矿任务遭到直接攻击或有敌军沿道路压近时，优先沿用统帅的完整防御程序。

预计接触早于部队救援时，农民走已通过威胁覆盖检查的道路，停靠在部队身旁，并用原生队列恢复原矿点。接触下界按物理火力范围与速度计算，救援和撤离时间按道路及地形计算。暂时撤离的任务也计入原人手预算，不因短暂移动重复补工。友军矿与不能由主力步行到达的地形保留原分工。
