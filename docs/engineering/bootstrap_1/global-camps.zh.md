# bootstrap_1：从基地周边到可达陆地的刷野选择

父版运行时与 `78e0d8a0827b4a4439ab69695dacf95052473e1a` 相同。

正常 Lone Market 骑士保存点在 10200 有三座采矿基地、十六工人、满血主力与两名佣兵，但主力回家闲置。剩余营地即使同陆地可达、道路安全、军队战力足够，也可能被旧“距起始基地 2600 内且距任一基地 1500 内”的范围筛掉。

军队计划显式指定刷野区域：旧版使用原基地周边营地，候选三路线使用同一片可达陆地上的未被敌军争夺营地。选择仍支付真实道路长度、检查每名士兵经过其他营地的风险及战力和聚拢条件；基地防御、敌军压进、我方势力范围和正在进行的攻击判断保持。没有新增距离参数、记忆状态、地图／种子／对手分支或备用选择器，两个运行时文件 +6／−2。

验证：

- 56 项不同原生 SDK 场景通过：十二个两族／三路线／镜像远营地完整规划器场景、14 个道路风险／道路排序、11 个既有 v7 刷野和十九个基地矿区防御。十二个新场景都实际清营且零永久损失、零支出；精确父版十二场均因未清营失败。
- 27 个历史公开策略帧的 79 条指令及内存与父版一致。原冻结 revision `dba796cfc152379adad9988a1314f94ffc736137` 和 54 个源码哈希保持。
- 同一正常 10200 世界续到 13200：候选累计九名守卫击杀、父版七名，两边三采矿基地、十六工人、零永久损失且均有一名三星单位。候选三星枪兵 417 经验、167.75／260 血，已下达避免交战的恢复命令；装备仍不足。不能把“更早清掉两名远守卫”写成“只有候选能获得三星”。

本批没有完成全图零损失竞速或完整地图／对手组合强度验收。海岛须由运输任务接上，不将跨水直线距离当成陆路可达。
