# bootstrap_1：地形移动预测用于炮弹与地面技能躲避

距离长短不等于能否赶在技能命中前逃离。旧躲避逻辑对直路用几何长度、绕路用无地形权重道路长度，再除以标称速度，泥地会得到错误的到达时间。

## 共享度量

三个运行时文件新增 33 行、删除 14 行。`groundSegmentProgress` 使用原有地形积分内核，同时服务等效裸地行程代价 `groundSegmentTravelCost` 和连续移动进度 `groundSegmentAdvance`；不复制寻路或积分算法。`groundMoveForecast` 在其上明确计入普通移动命令的 5 单位到达容差。躲避逻辑使用移动预测判断走向，用 `routeTravelTicks` 判断能否在命中前到达逃离点。

直线与火力范围、道路长度、地形行程代价、估计 tick 和预测位置各自保留含义。沿线预测要求已确认的畅通地面路段；不包含单位与建筑绕行、状态效果和逐 tick 边界取样误差。没有新缓存类型、距离场存储或备用寻路器，已有道路与代价场的 128 项共同 LRU 及数组复用保持原样。
