# 全图道路采购与归队

精确父版为 `3e40d3b1cdebf7a41e17fbdc62bcf82eb9206cbb`。原采购必须处于主力直线 900 范围及本土连通地面，任务 60 秒后过期；远处有货且道路安全的商店因此无法利用。

候选三路线以 `safeLandTravelTicks` 的真实地形道路和逐段攻击覆盖选择商店与采购者，以 `nearestByRoute` 选择可达归队基地。不借助跨水直线，不扩大购买范围，不设置新的任务过期时间；没有商店的地图不生成采购目标。单名采购者与主力集结分离，海运、刷野、袭扰、雇佣与拾取的已有任务仍保留其单位。

`shopPurchaseAt` 只提取原采购需求事实，旧策略继续原范围、选店、限时及物品优先顺序。候选通过统一经济目标队列预留和实际支付金币，抵达使用现有雇佣采购优先级 64。普通 SDK `buy` 明确指定真实 `recipientId`，买入后避战归队。任务仅保存三个实体 ID、物品种类和归队标志，没有兼容分支或替代路线。
