# bootstrap_1：完成航次后释放运输船

真实岛屿开发中，永久乘员已经登陆，船上召唤单位仍让取消后的返航任务停留在旧出发海岸。召唤单位不断更新，运输船始终不能接下一项任务。

返航现在只等待永久乘员卸载。没有永久乘员时删除已经完成的航次，并停止旧卸载命令；临时召唤物保留在船上。仍有永久乘员的返航行为保持原样，没有改变资源、单位属性、决策周期或冻结策略。

24 个真实 SDK 场景覆盖三个 v9、两族、镜像和船上仍有永久乘员的情况；召唤由正常技能在甲板上产生。新实现 24/24，原实现 12/24。连同本地恢复、守护覆盖及已有海军、物品和治疗检查，共 332 项通过，TypeScript/Vite 构建通过。

同一 sapphireArchipelago / Grove / v9_summoner 无对手开发存档从 27000 重放到 30000：原实现继续保留旧返航任务，新实现清除该任务并进入现有维修流程。两边都是四个完成基地、三个实际采矿点，各矿五名工人；该窗口没有永久单位死亡。

这次修改解决任务释放，不证明扩张更快：轻伤运输船仍在原海岸等待维修，没有第五基地。后续需要调查维修安排和实际船体通行。正式全地图 1v2 验收未完成，既有 CPU 门槛问题也没有解决。
