# 原生道路覆盖与射击时序分开

PR #344 的 Production Deploy #38275295955 首次失败于岛上骑射手长期刷野。三个非镜像场景的骑射手都存活、零损伤，但原 24000 tick 时限内最后一只 golem 还剩 15 点生命；镜像对照通过。该失败部署没有重试。

道路检查使用真实攻击范围，微操继续在原思考与瞄准窗口预测敌人移动。之前在道路覆盖中再次加上敌人的下一次思考位移，重复收紧了接近范围，降低了刷野效率。现在只删除这一项加法，原完整道路检查、无伤约束、攻速、射程、思考频率和全部状态仍在；没有岛屿或地图特判、兼容路径或放宽测试。

最终 129 项 SDK 检查通过，包含全部六个原岛上刷野场景以及长途伏击、并行营地、原刷野与骚扰、冲锋、舰队、跨水和移动医疗。原 24000 tick、野怪清空、骑射手存活、零损伤、零阵亡和零消耗断言均保留。精确父版本六项岛上对照三通过、三失败。

运行时一行算式，类型没有变化。父版本最终 Node 20 项目构建通过；本修正没有再次执行完整本地构建，最终生产构建仍须在发布后核验。CI 新增骑士系列的两个镜像原岛上场景，生产检查已有全六项。冻结基线与 1620 格验收请求不变，正式验收未完成。
