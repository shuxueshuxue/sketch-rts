# 区域退避后的追击

v9_archer 对两个冻结 v8 的真实 pineshade 开局，在 tick 11400 → 12000 损失八个常驻单位。伤害来自敌方叠加防御塔和附近龙群，主力进攻 / 退路仍需继续处理。一个单独刷野的骑射手从 109 血降到 31 血。逐个正常 15 tick 决策记录确认，风暴躲避任务在它离开区域后持续占有控制权，连续下达移动到当前位置的命令；骑射手原地自动接敌，龙追上后击中它。

`shellEvasion` 现在把“已离开区域”与“可以原地等待”分开：区域任务仍有效时，若敌人将在下次决策前进入攻击 / 技能 / 物品距离，调用既有 `mountedEscape`，同时避开区域和追击者。旧移动目标也经过这个判断。其他时刻沿用任务等待；区域结束后的控制权释放保持原规则。退避算法本身没有修改，新增控制权覆盖它本来就可能发出的正常 holdPosition 命令。

24 个真实 SDK 场景覆盖三种 v9、镜像、龙 / 食人魔追击与已在移动 / 原地等待两种任务状态。父版本 12 项通过、12 项龙追击失败；候选 24 项通过，骑射手均不受伤。另有 131 项已有区域 / 炮弹 / 工人躲避检查和 94 项骑射手 / 营地 / 前线恢复检查通过，共 249 项不同检查。TypeScript / Vite 构建通过，没有改写既有断言。

同一 tick 11400 世界、三个玩家的完整 AI 记忆和 nextId，公共 PR #324 运行时与冻结对手，正常资源、规则及 15 tick 决策周期，继续 600 tick：父逻辑的骑射手受到 78 点伤害，候选没有受到伤害，末次决策仍是 109 血。该结果只证明这一段局部交战中的改善；主力塔下伤亡问题仍在，不能称为整局无损刷野或新的对局胜利。

这是新的 AI 行为修正，不是 CPU 优化。PR #324 的生产部署 38165577397 在全部前置功能检查通过后，裸图 14158.656 > 12000 ms、ladder 16697.516 > 16000 ms；线上仍是已成功部署的 PR #323。没有重跑该失败提交、提高门槛或取消发布检查。本批新增 24 个场景加入 PR / 生产检查，正式全地图和未见种子验收仍未完成。
