# 返矿按道路择优

工人原采矿点失去己方基地后，既有调度会在可达己方矿点中优先填较空的矿；此前同人数时比较直线距离，容易让工人绕森林去看起来更近的矿。现在负载优先顺序保留，同负载矿点复用 nearestByRoute 选择较短的实际地形道路。基地与矿的关联仍用物理距离。运行时一文件 +4/-2，没有新增状态或距离参数。

两个镜像真实 SDK 场景分别放置隔墙近矿与同侧短路矿，基地遵守现行 216 距离布局。900 tick 内候选工人实际开采同侧矿并将金运回，隔墙矿未消耗、没有支出或死亡；精确 #285 父版两场都未开采同侧矿而失败，没有据此编造父版收入值。

六文件共 28 个不同相关原生检查通过，27 保存决策／79 条旧指令及记忆完全相同。固定最终源码 Node 20 真实子路径客户端／服务器生产构建实际 exit 0。不计正式矩阵胜场；该道路估算遵循底层地形路线，不代表包含单位身体绕行的精确到达时间。
