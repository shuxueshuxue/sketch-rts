# 战间休养与范围伤害任务交接

父版为 #317，`7de2bac7863ce619269a9697299e369d42f0a78d`。正常骑士 1v2 开局中，两名枪骑兵在 6000 tick 只有 12 / 42 生命，已经有月井，却继续在前线闲置。原有主将只在防守分支把重伤前排送往治疗设施。

## 实现

三个运行时模块 +47/−14 行。提取原有安全治疗设施查询，供主将、休养及范围伤害交接共享；没有新增持久状态、缓存或调参常量。

- 已建成、存活且当前不受敌方物理攻击覆盖的己方治疗设施，接纳重伤的可治疗永久陆军。
- 已在实际治疗范围内时直接休养，包括设施隔墙但仍能正常治疗的情况。需要行军时按可达道路选择设施。
- 现有非战斗移动命令及实际治疗范围维持休养归属，直到满血，再释放给军队。运输、专门任务和正在命中的范围伤害保留已有优先级。
- 躲避范围伤害的移动使用非战斗移动，避免到达短距离躲避点后自动重新迎敌。病人离开危险区域后，把控制交回休养任务，不必等整片火或风暴消失。

没有地图、种子或对手版本分支；兵种属性、金钱、维护费、治疗速度、思考周期和 CPU 上限均未变。治疗者仍使用原有技能模块，没有另加治疗补偿。

## 原生 SDK 检查

273 项不同相关检查通过，构建和类型检查通过。新增 40 项：三路线、双种族、镜像下的战间休养、实际治疗射程与道路不通的区别、真正风暴中的任务交接，以及 4 项治疗者自身施法检查。

其中 36 项病人场景在精确父版中 4 通过、32 失败：8 项不开始治疗，12 项离开已覆盖自身的治疗范围，12 项不能在风暴仍存在时继续走向治疗设施。候选全部通过。重伤由实际技能造成的场景保留原生伤害和冷却；隔墙的度量场景使用预设伤兵，不能冒充自然开局。

63 个普通 v2/v3/v5/v6/v7/v8/v9 状态，167 命令及完整记忆与父版相同；54 个已批准冻结源码哈希不变。
