# 扩矿威胁使用攻击几何与陆地道路

过去选矿和建矿前准备防护都把800范围内的敌军算作威胁，即使森林墙让近战部队必须绕到地图另一侧。bootstrap 的两个决策现在共用 enemyExpansionPower：strikeGap 已在实际攻击范围内则算威胁；尚不能直接射击的陆地兵须有不超过原范围的 walkingDistance。先用物理范围排除远处敌军，再查道路。

舰船及甲板单位保留原海上物理范围，道路查询只描述陆地步行。普通策略显式传入原 enemyPowerNear，冻结 v5/v7/v8 不变。没有新阈值、状态、默认分支或地图／敌方版本特判；运行时三文件 +25/-7。

十四个新 SDK 检查：两个镜像射手隔墙直射场景仍拒绝近矿；三路线、两阵营、镜像共十二个近战绕墙场景在1500 tick内正常花钱建成近矿基地且无己方死亡。敌军使用普通 attackMove，真实道路行程超过该窗口。精确父版十二个付费扩矿场景失败，两个直射场景通过。

这些检查调用经济及建造后返矿模块，明确隔离派系招募配额，不称为完整策略竞速。连同既有选矿、清野、友军矿权、岛矿、增援与经济检查，十文件176项不同检查通过。27个保存状态／79条旧版命令及策略记忆逐项一致，原冻结54文件哈希保持。

三份真实正常1v2战局的十八个保存决策前后相同，没有触发本次修正。没有补金币、修改冻结基线或计正式矩阵胜场。最终生产构建和精确提交 CI 是合并门禁。

首次生产构建发现测试场景返回的兵种类型被推断成 string；补显式 TrainableUnitKind 注解，运行时与测试行为不变。最终固定源码 Node20 子路径客户端／服务器生产构建实际 exit 0，精确提交 CI 仍为合并门禁。
