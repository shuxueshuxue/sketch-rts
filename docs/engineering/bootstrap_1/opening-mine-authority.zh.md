# 单基地附近自然矿的建设顺序

#356 首次生产在原有 expansion-authority 的十二个普通开局场景失败：无条件优先远处清空矿，让第一条经济线没有完成附近自然矿的清野、建设和回交矿袋。上传及发布步骤跳过，线上仍为已核验 #355；未重跑该失败部署。

现在唯一一座工作基地先依照原道路距离选择附近自然矿；多座基地或没有工作矿时，继续优先可建设的安全清空矿。排序函数明确提供数值优先级，原指挥器与单基地为零，其他经济按原建设就绪判断给零／一；两处调用均为必填，没有默认值、兼容分支或新持久状态。原建设站位共享、盟友过滤、道路安全、价格、兵种属性、资源和思考频率不变。

十二个原开局断言逐字保留：清掉自然矿守卫、只在自然矿建设、真实回交第一袋矿、资源守恒。整项失败的生产检查连同原空矿和双矿扩张检查，共 465 项通过，Node20 完整构建通过；这些自然矿场景加入 PR CI。

此前 Grand Estuary 的 12000→16000 窗口起点有两座完工基地，本条单基地规则不会改变其清空矿排序；布尔就绪改为数值排序在该条件下等价。没有重跑该窗口，亦不声称新的对手胜局。完整 1620 格与未见种子仍待完成。证据与新代码哈希见同目录 receipt。
