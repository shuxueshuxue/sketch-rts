# 按可执行任务招募独立骑射手

Grove 三条 v9 路线在两处有效矿、六个永久战斗单位和既有马厩成立后，根据真实出兵口到可清矿点或暴露采矿线的任务提出一个骑射手需求。安全估计使用未升级单位的原始数值；已有骑射手时提出射程和速度升级需求。单位价格、资源、数值、状态结构、思考频率和冻结基线不变。

招募和实际任务共用矿点、道路和骚扰选择。骚扰射击点排除建筑占位；面对静止目标，安全射击直接指定攻击目标，避免 aim 自动选敌使骑射手站着不攻击目标农民。

24 项局部 SDK 场景覆盖三系列、镜像、刷野/骚扰和安全/封锁对照，真实付费出兵，完成目标且骑射手零受伤、永久单位零阵亡，包含原野怪赏金的资金账平衡。已有六人前线由局部 doctrine 保持，这不是完整正常对局。父版本 12 个危险路线对照通过、12 个有效任务未招募。

最初广泛检查为 212 通过、4 失败，发现抽取函数后漏导入 isWalkable；修正后受影响 42 项通过，合并升级资金改动后相关 87 项通过，去重后的最后结果覆盖 216 项全部通过。Node 20 构建完成退出 0。

同一实际对局 6000–10000 tick、全部记忆不变的窗口两版均零阵亡且没有招募骑射手。初始检查点没有马厩，期末没有合格剩余营地；不据此宣称战力或胜率提高。完整 1620 格及未见种子验收仍待完成。
