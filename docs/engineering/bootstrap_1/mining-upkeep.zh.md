# 毛产出与可支配收入

> 本文为旧分档规则下的历史诊断记录；当前规则见[连续采矿维护费与金币结算](../mining-upkeep.zh.md)。

实际返矿和生产诊断不能把矿量减少当成可支配收入。现行维护规则在每次卸金时按当时人口计算：人口0–50原额入账，51–80按70%，81及以上按40%，每趟向下取整。每趟10金因此分别入账10、7、4金。跨人口档位的整局收入不能用最后一个档位简单乘总毛产出。

将原有 upkeepGoldIncome 及两个比例常量从模拟器原样移到共用采矿模块，模拟器调用同一个函数。阈值仍来自现有 catalog，计算顺序和取整原样，没有新状态、规则或默认分支。运行时两个文件 +13/-11；后续AI与诊断可以直接调用真实入账规则。

62个既有采矿、等待队列和相关模拟检查通过。编译精确父函数与候选，12221组金额／人口输入相同，八个不同档位／金额的真实卸金场景完整世界相同，正常战局24000→24300 tick的完整快照及nextId相同。27保存决策／79旧指令及记忆一致，不更新冻结基线，不计性能改善或正式矩阵胜场。
