# 靠岸航路保留原地转向

父版：`6d23e91527d97259174edfc28c54633c67024b71`。

直接船舶航路在删去重复起点时只比较圆心位置。一个必要的原地转向也具有相同圆心，因而被删掉；执行器拿到的是没有完成起始转向的直行段，反复规划也不前进。第一点现在只有在位置及航向都没有变化时才可删去，沿用原角差函数和精度，无新状态或数值参数。平移距离为零不代表船体姿态没有变化。

Sapphire 普通保存世界的运输船在 18000 tick 停于 (6128, 2672)，装载岸点是 (6096, 2960)。相同完整世界仅物理模拟 60 秒，父版仍原地、船体至岸间隙 234.598；修正版沿合法连续航路至约 (6032, 2928)，间隙 19.084，普通 move 自然完成。没有传送、增大登船范围、改航速／转向或跳过 SDK。

最终两个真实 SDK 原／镜像靠岸场景使用正式六席地图，先由空场模拟自然推进到同一 18000 tick 风场，再生成正常运输船并下普通移动命令。镜像同时反射地形、起终点、航向与风向，保留风速和规则。60 秒内靠岸，整个过程船体合法，零单位损失；精确父版两场均停在原位，234.598 间隙超出原工人登船范围。最初默认两人生成的简化测试在父版也过，被替换，不作为改善证据。

100 项已有船体导航、连续运动、通道、靠泊、真实登船／登陆及 AI 海军检查通过，连同两新场景共 102 项不同检查。27 个 v5／v7／v8 历史规划帧、79 条指令及内存与父版相同，冻结归档原样。

正常 Sapphire 保存世界继续至 27000，运输船已实际装载八名闲置工人并运向现有岛矿，无新增永久阵亡。第二岛基地仍未建成，主矿耗尽后任务改为搬迁；因此不宣称完成全地图扩张或零死兵竞速，也不是正式强度胜场。经济统计尚把上船工人当作不存在，额外训练三名工人，是后续独立修正目标。
