# 进攻队按道路集结，减少越权道路评估

落后的雇佣兵仍属于进攻队，并不代表它已经和主队在一起。真实失败局中主队北侧前进、雇佣兵远在南侧，直接向敌方基地走让它单独接触敌军。普通进攻现在沿既有道路 700 距离判断队员是否相聚，选择力量最大的邻近队列；未接敌时主队保持，落后单位沿检查过的原生道路汇合，再一起继续进攻。主队进入已知攻击或施法覆盖时继续原战斗指挥。集合目的地旁的营地也属于避让对象，不能沿用攻击敌方基地时允许目标旁交战的语义。

已经成队的情况先检查一个共同队员，确认即可跳过全部邻近队列搜索。后排治疗兵由原模块控制，进攻绕野只计算前排实际成员。没有新增持续任务状态、计时器、距离阈值、数值、资源或地图／种子分支。冻结对手归档原样。
