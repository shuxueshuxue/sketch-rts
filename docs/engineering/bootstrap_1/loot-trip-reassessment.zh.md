# 拾书养星任务途中复核道路

出发时安全并不代表整个任务一直安全。真实失败局中的养星长枪兵正在拾取经验书，敌军进入其路途后，控制器仍不更新命令，最终阵亡。现在任务从出发到返航都检查同一条包含建筑占据的原生 steering 道路。书点变得危险时，取消拾取并沿已检查的道路回到原基地；返程被封锁则结束拾书任务，停止原拾取命令并把单位交回军队控制。

任务增加一个明确的 `returning` 布尔阶段；取消拾取后也能完整返航，不需要猜测原生移动队列或添加计时阈值。原有经验书优先培养、携带者评分、基地选择与正常拾书后返航语义保留。没有旧任务数据适配、默认阶段兜底或指令重试。

原生退路几何抽出 `retreatLandRoad`，同时返回道路点和行军时间。精确站位仍通过原有 `retreatLandTravelTicks` 的到点范围验收；回到建筑旁则由任务使用既有 180 距离验收实际道路终点。两者共用原生道路和威胁覆盖计算，不把建筑中心当作士兵可占据的位置。无新增距离、资源、单位数值、地图或种子分支；冻结策略归档未变。

182 项不同相关 SDK 检查及 Node 20 构建通过，包括原有三颗星培养与返航、道路覆盖、空矿建设、雇佣兵和商店检查。新增 24 个完整指挥场景覆盖三个候选、两个阵营和镜像：安全时正常拾书、使用并返航；敌军在真实移动中进入路线时，取消未完成拾书，单位满血返航、任务解除且不支出资源。精确公开父版本 `66dfd2d17f0e55933d1955027cb04246bd6dea57` 的相同场景中，12 个安全对照通过，12 个截击场景因单位受到伤害失败。

真实规则 2 失败局第 6000–7200 tick 的短窗口，基于已发布的绕野改进，永久阵亡 2 → 1；原养星单位从阵亡变为存活，期末 173/173 HP，常备军 6 → 7。候选已有任务根据观测到的 `pickupItem` 明确初始化为取得阶段；冻结对手记忆原样。此对照只证明途中返航，不能作为新开局正式胜局，也不声称敌军封锁时能保证无伤。

完整各地图矩阵与最终未见种子验收尚未重跑；雇佣兵途中护送、阵地与游击组合、经济全图扩张、岛矿与伤兵保存继续。
