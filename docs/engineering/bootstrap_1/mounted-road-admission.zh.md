# 独立骑射手先核验实际接近道路

安全的射击站位并不保证能安全抵达。长途骚扰现在按原道路长度顺序逐个核验原生行军道路，选能避开已知攻击覆盖的站位；已经进入原 750 局部交战范围时继续由原微操管理。刷野接近的射程边缘点还核验完整原生道路与攻击覆盖，避免直接攻击命令在途中穿过路边塔。单个任务分派后只移除实际领取任务的骑射手，其他骑射手继续寻找任务，能同时清理不同营地。

运行时两个模块，增加 14 行、删除 5 行；复用既有道路、离开覆盖和攻击范围函数。原局部范围、思考频率、单位数值、资源、持久状态、任务人数上限和冻结策略不变，没有地图特判、默认补值或兼容路径。

123 项 SDK 检查通过，含原刷野、骚扰、森林绕行、受伤任务延续、冲锋窗口、舰队优先级、跨水任务和移动医疗。新增十二项覆盖三系列、镜像与有无路边塔：道路安全时完成原骚扰；道路被塔覆盖时拒绝该长途任务，两名骑射手分别无伤清掉两个营地。全部在任务完成时两骑存活、无生命损失、无资金消耗。父版本六项正常道路对照通过，六项伏击场景失败于错误领取骚扰任务。

第一轮原型在任务分派和刷野接近中失败；实际命中记录显示镜像场景第二个骑射手被路边塔命中，随后补齐接近道路核验。原十二项场景时限由 1200 调整到 2400 tick，以包含两次完整行军和刷野；终止条件明确为任务完成，两营地清空、生存、无伤和零消耗的断言保留。最终原有测试全部通过，没有发布中间原型。

最终 Node 20 项目构建退出 0。本轮以实际 SDK 局部模拟迭代，没有重跑全局矩阵；1620 格官方地图和未见种子仍待验收，不宣称正式胜局。
