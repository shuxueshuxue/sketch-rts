# bootstrap_1：混编骑射手地形压力试验（未发布）

压力场景为八名普通骑射手、四条普通红龙、真实狭岸浅滩，同一清营任务同时执行 600 tick；三个 v9 家族及镜像方向均测试。任务记忆由 SDK 场景初始化，用于暴露密集混编的控制问题，不代表普通清营分配器会自动派八人刷一个营地。检查仍要求八名骑射手无伤、真实命中、零永久损失与花费。

线上 #307 的正向局部观察中，两名骑射手各挨三次 42 伤害后死亡。第一处误差是沿浅滩逃跑仍按标称 90 速度估计；第二处是全方向危险时，避开队友的排序优先于逃离敌人的距离。共享地形移动进度和危险排序修正后，正向三家族均无伤，镜像三家族各受一击 42，全部八人存活。再计入普通移动停止容差后，仍是 0 / 42 伤害，未满足六项全部无伤要求。

| 后续候选 | 正向伤害 | 镜像伤害 | 处理 |

不改攻击、速度、血量、资源或检查门槛。未发布骑射手运行时的这些候选，也未将压力局部结果算作完成清营或新正式胜局。基础移动预测在普通工人 SDK 中验证了 0.4 / 1 单位误差，另用于已取得八个真实炮弹场景改善的地形躲避批次。
