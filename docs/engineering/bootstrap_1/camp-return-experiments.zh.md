# bootstrap_1：清营返程的试验界限

最初的往返场景包含一个无必要断言：存在沿途龙营时必须完全不清目标弱营。四个射手、骑士场景能安全清营，却被该断言判失败；不能将最初六个失败统称旧版受袭。最终验收用实际受袭和存活，不规定必须取消所有清营。

移除该断言并采用远处友军驻军的单机场景后，父版本十项通过、两个召唤师镜像实际受袭。只检查集合点的回程仍有遗漏，营地内部的退路也需要检查。原始网格流场路径不等于可见地形的直接移动；把建筑遮挡混入纯地形度量又会误判基地中心的直线。最终候选以显式的纯地形视图统一这一语义，建筑、单位绕行及流场转角平滑仍不在该估计内。
