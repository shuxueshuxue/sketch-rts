# 按可用生产位预留下一轮军费

原预算为每座已有生产建筑的下一轮单位保留金币，包含当前已经在训练的队列；忙碌生产位的这笔预留会挡住已请求的第二座建筑。现在区分两个量：是否仍有该建筑的兵种需求，以及当前空闲生产位需要的军费。忙碌队列保留需求，新增建筑不再为它们预付另一轮；空闲生产位和首名治疗者仍保留资金。人口波次预测、原配额、投资优先级、单位属性、价格、资源和15帧思考原样。

一处运行文件，5行增加／3行移除，零新增持久字段、状态结构或默认／兼容路径。预算为0不再等价于没有生产需求。202项原生SDK检查和Node20完整构建通过；包括首名治疗、科研、殖民、渡运、空矿与原生产波次断言。

十二项新场景覆盖两种族、镜像和忙碌／空闲／首名治疗三种状态。正常500初始金币支付一名法术兵和一座农场；既有军队、生产建筑和工人属于隔离场景，不能当作正常开局。忙碌四场景实际建成第二座生产建筑，空闲四场景先训练已有队列的下一单位，首名治疗四场景保持其资金并实际训练治疗者。零损失、普通价格、现金守恒。同一源码父版本8通过／4失败，四个忙碌场景不投资。
