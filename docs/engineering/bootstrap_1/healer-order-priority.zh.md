# 恢复牧师自疗的命令优先级

#349 首次生产部署在 front-post-continuity 的四个原始自疗场景失败：通用技能已让出 heal，而更早的治疗站休养命令占用受伤牧师，导致后面的治疗模块无法施法。任务没有重跑，线上仍是已验证的 #348。

修复将已有 medicalRecovery 从后排位置移到 abilities 之前，同一牧师的治疗单位归属和命令均先于后续休养。仍由原治疗模块分配本帧的治疗，通用技能让出已分配的 heal；没有按场景添加例外、修改断言、兼容路径、单位数值、资源、状态或思考频率。

213 项实际 SDK 检查通过，包含原四个失败场景及整个连续休养文件、三系列两阵营镜像的 12 个同时治疗场景、岛屿恢复、骑射清营、召唤塔推进和小军队付费治疗。CI 加入此前只在生产测试覆盖的完整 front-post-continuity 文件。#349 的 Node 20 项目构建已通过；这项修复仅移动两个既有脚本引用，最终组合构建由新发布的生产流程验证，不宣称已完成本地重复构建。完整 bootstrap_1 验收仍待完成。
