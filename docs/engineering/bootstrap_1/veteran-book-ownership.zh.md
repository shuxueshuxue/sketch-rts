# 经验书分配与任务归属

父版为 `6e407ce9c5ac6f68fc34cb9a834c0e6d5ae8cc3d`。远程培养已经指定老兵，旧近身拾取模块仍能将同一本经验书交给途中路过的新兵。现有任务声明只保护单位，没有保护物品分配。

候选的 `items` 脚本向原物品模块提供明确的可分配物品集合：保留全部已携带物品以继续正常使用，只将地面经验书交由培养模块分配，其他已指定的战利品也不重复分配。过滤发生在生成近身拾取指令之前，因此不会先让等待分配的书占满指令名额，再遗漏旁边可拿的卷轴。既有消费逻辑只有一个调用者，不新增持久状态、价格、经验门槛或单位属性；旧版脚本直接使用原物品模块。

三路线／两族／镜像十二场实际先拾取、消费第一本普通 160 XP 书，得到二星老兵；新兵站在第二本书旁边。父版将第二本书交给新兵，出现两名二星；候选只交给老兵，实际达到 320 XP／三星，归队并释放任务，新兵 XP 保持零。另一个实际 SDK 场景检查两本书旁边的守护卷轴能在第一帧被另一名士兵拿到。金币仍为正常 500，单位零损失。

整合全图采购后，60 项不同原生检查通过：13 项新增分配、13 项原拾取／归队、13 项采购、16 项雇佣／人口预算和 5 项原物品策略。27 个历史规划帧的 79 条指令和内存仍完全一致；冻结 revision 及 54 个源码哈希不改变。

普通 Lone Market 共同 10800→12600 世界中，候选与父版均保持三采矿基地、十六工人、两名新增守卫击杀及零新增永久死亡，但仍零三星。追踪确认 `treasure-gen-4` 在 11682 tick 的浅水格 `,` 上随野怪死亡掉落，按既有 `settleGroundItems` 规则当帧沉没，没有实际拾取／消费。现有测试明确覆盖浅水沉没，本次保留规则；后续须改进带战利品野怪的交战位置。不能将重复分配修复称为该保存世界的三星改善。
