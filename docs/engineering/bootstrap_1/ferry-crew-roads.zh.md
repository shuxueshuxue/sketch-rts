# 登陆士兵按到岸道路与速度排队

运输船原来按士兵到船的直线距离选择登陆部队。沿岸隔墙时，直线最近者要走长路；有限载重及真实甲板几何又使先选的士兵占用空间，后来的短路候选不能加入。

bootstrap 三路线通过必需的 crew-order 接口复用 shared/route-selection.routeArrivals：目的地是登船岸边的陆地点，各士兵按自身速度和陆地道路到达时间排序。普通 planNavalTactics 显式传入原直线排序。工人优先、两名工程工人、载重、几何装载、守家兵力与登陆安全判断保持原规则；无新记忆、阈值、地图或对手版本分支，没有缺省或兼容路径。运行时两个文件 +14/-6，净增8行。

道路时间不包含建筑／身体绕行、临时减速、登船操作与船舶航行；海上航行时间不能用这项陆地度量代替。
