# 清野伤兵会合与危险中的退路排序

清野恢复以前只在接战阶段接管伤兵，并统一退到集合点。Pineshade 的一次真实观察中，几名低血量士兵停在集合点附近，两名治疗者却分别在 400 和 1000 距离之外；下一轮部队还在集合时遭遇野怪，伤兵又在恢复模块接管之前死亡。

候选在集合和接战阶段使用同一恢复逻辑。伤兵能接受治疗时，在当前安全的本方治疗者中按真实道路选择会合点；没有可达的治疗者时仍执行该清野任务的集合目标。机械单位遵守现有治疗规则。道路可达性/旅行时间继续复用 `nearestByRoute`、`routeTravelTicks`；敌人和地面技能覆盖继续使用实际直线范围。

第二个实战问题是，所有短步都还在攻击覆盖里时，身体避让评分优先选出很短的动作，伤兵反复结束移动后还击，再受伤。现在这种状态先比较脱离威胁的余量；已经安全的选项保留原有身体避让与会合目标排序。没有修改游戏移动、战斗、技能、生命、金币或人口规则，没有增加缓存、状态或阈值。
