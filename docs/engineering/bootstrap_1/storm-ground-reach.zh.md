# 风暴法杖的范围施法度量

模拟器按单位中心检查法杖施法点：点必须在施法者320内，落点145内的敌人中心受到伤害。原AI只找320内敌人，把“目标中心不在施法范围”误当成“地面技能无法覆盖”。

shared/combat-geometry 的 areaCastPoint 只处理中心几何。近目标用其中心；外圈目标用两个圆在径向上的共同区间中点，没有共同内部则不选点。该算法不使用道路距离、单位身体半径或墙体路径。已有 strikeGap、bodyGap、walkingDistance、routeTravelTicks、routeArrivals 继续分别表达射击点、爆炸身体接触、地形道路长度、固定速度行程和道路到达排序，不混用度量。

三条bootstrap路线显式传入地面选点函数，在规则给定的320+145范围内找可覆盖目标，优先覆盖更多非临时召唤物，然后更多敌人。普通策略显式传入原最近非spirit目标选择；该注入参数必填，不改变物品数值、冷却、价格、军队或地图规则。

48个三路线／两族／镜像SDK场景覆盖外圈目标、远处聚集区、步行不可达的隔墙目标及过远目标：合法施法实际伤害、友军不伤、零金币支出、过远不消耗冷却。精确父版36个命中场景失败，12个过远场景保持通过。七文件120项不同相关原生检查通过，27保存决策／79旧版指令及记忆一致，54文件冻结清单不变。

正常Pineshade／Grove／v9_archer对冻结v5+v7，同一24000→24600保存窗口：父版法杖冷却0，候选75，确认实际使用；起始永久战斗单位损失2／1，结束战斗单位28／29、总剩余生命2731／2799。双方金币51，采购同一名长枪兵，仍有两基地、没有胜负。损失的单位ID不同，候选仍死一名长枪兵，不宣称无损、净击杀收益或正式矩阵胜场。
