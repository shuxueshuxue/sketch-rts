## 继续中的跨岛候选

自动运输骑射手并让清营任务保留矿点，尚未发布。三个家族的镜像自动登船、登陆、无伤清两个食人魔、清营后接续两名拓荒工人等 21 个 SDK 场景通过。

在 Sapphire Archipelago 单机存档的真实 AI 续跑中，原始候选清掉 7 名守卫，但甲板祭司自动追击上岸后死亡，射手随后也上岸并被远征规划器派入另一营地。候选有 2 个新增永久单位损失，对照无新增损失，因此没有合并这一批。

单独让船员保持位置仍使战舰把甲板带入红龙射程，两人仍死亡；此独立尝试撤回。将骑射手已分配的营地从舰队主动进攻候选中排除，并让这类独立刷野渡船不占用战斗护航队后，同一死亡前存档的 51000–54000 局部续跑没有新增永久损失；两名船员保持满血返回港口。运输船仍受 72 点守卫伤害，另有一次真实友舰碰撞，这段窗口没有解决全部保存与航路问题，也不是从原始 42000 存档开始的整批对照。

补充舰队协同场景时，初版只应用最近合法船位的坐标而没有应用合法朝向，造成卡船；这些失败不能作为有效策略退步证据。修正初始船位及航向、断言船体可通行后，三个家族六个镜像 SDK 场景通过。当前线上 #304 的六个有效镜像对照全部失败，均损失战舰及两名船员；任务分工修正的六个场景均通过，无己方伤害、永久损失或花费。

## 度量核对

现有 `walkingDistance()` 使用无地形速度权重的道路距离场，不能把它称为已考虑泥地与浅滩的实际到达时间。含地形减速的行程估计已在 #305 合并并部署；保持攻击直线/船体边界距离、道路长度、地形行程代价和实际 SDK 到达观测的含义分开。

本轮没有新增正式验收胜局。1620 个正式格子与未见种子验收仍未完成；bootstrap_1 继续开发，不能标记完成。
