# bootstrap_1：受威胁时离开原地

骑射手在悬崖拐角受两个红龙夹击时，所有候选终点的武器距离余量均为非正数。原排序仅在 `avoidCombat` 为真时优先实际移动；刷野调用为假，于是可以连续选择自身坐标，完全没有逃离危险区域。

修改排序中的一个条件：所有终点均受威胁时，两个安全性同类候选之间优先实际移动。保持原来的可行道路、船体碰撞约束、候选步长、射击与到达逻辑。

新增两个镜像真实 SDK 回归场景，使用正常属性的一个骑射手和两个红龙。在相同 300 tick 窗口内，原版首条移动命令距离为 0；修正版首条移动距离大于 5，骑射手存活，单位损失和花费均为 0。这个已被包夹的初始场景验收存活与实际位移，不宣称无伤清营。

另一个原有群岛存档的局部微操对照中，双方都使用尚未发布的同一套运输策略，只替换本函数：旧函数下骑射手受到六次 42 点伤害并死亡，修正版在同一个 600 tick 窗口内保持 211/211 HP。它是局部消融证据，不是完整新旧策略胜率。

两个正常红龙的海岸清营长窗口作为正向控制，当前线上函数和本修正均可无伤清完。自动跨岛刷野与采矿协同仍在独立迭代；正式全地图胜负矩阵与未见种子验收仍未完成。
