# 避战移动离开近距离射击窗口

骑射手利用敌方冲锋的最小施放距离，在近处射击。原逃脱采样器也把伤兵回撤和躲避地面法术限制在这个窗口里，要求候选点仍靠近敌人，甚至原地停住。明确避战的命令因此仍可能维持近距离交战位置。

现在仅在允许交战时保留近距离射击窗口；调用者要求 `avoidCombat` 时，采样器可以选择离开该窗口的移动。运行时代码是一处条件，原射击、移动评分、到位距离、价格、单位数值、状态和思考周期不变。冻结归档不变，没有默认值或兼容处理。

75 项不同 SDK 检查及 Node 20 构建通过，涵盖原无伤刷野、冲锋与预瞄、施法者支援、岛上骑射手、地面法术及伤兵移动。新增八个实际移动场景覆盖两种冲锋兵、镜像、避战和交战意图：伤兵避战时离开最小施放距离，交战对照仍保留窗口，生命与资金均未损失。公开父版本通过四个交战对照、失败四个避战场景。

另从尚未发布的混编试验实际第 9000 tick 保存状态恢复全部控制器，原生继续 300 tick；只替换同一编译产物中对应的一处条件。这个复杂场景的骑射手在两版都阵亡，不能宣称修正已经救下它或带来正式胜局。后续仍需解决道路穿过其他敌军及携带攻击物品的敌人威胁。1620 格官方地图与未见种子验收待完成。
