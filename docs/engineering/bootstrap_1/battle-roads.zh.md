# 进攻目标与援军的道路度量

此前将军用目标到敌军的直线距离判断当地守军，并把双方到目标的直线距离比较当作敌军能否先到。隔墙的守军会让安全攻击停住；必须绕墙的己方反而可能向已有敌军会先赶到的基地出发。

新增ground-threat模块，共用routeArrivals与walkingDistance。groundThreatWithin先保留真实strikeGap射程内的直接火力，再判定陆地道路；groundRespondingPower用每名实际单位的速度和道路到达时间，统计能在完整己方前队之前到达的两方援军，已经能够直接射击的敌人也计入。目标评估与持续进攻的当地敌军使用同一度量。扩张不再复制该地面判定，海军与甲板仍保留原物理海域范围。

将军计划增加两个必填度量入口；普通控制器显式提供原直线范围与原援军选择，bootstrap显式提供道路判断。没有可选入口、默认路径、备用距离、持久记忆、阈值或兵种数值调整，也不读取地图名、种子或对手版本。

道路到达时间是当前单位speed下的地形路程估计，不含建筑和单位碰撞绕行、状态变速或攻击完成时间；不适用于航海。该模块没有把这些时间估计称为实测行军耗时。物理射程与道路范围保持两种语义。

36个真实SDK场景覆盖三路线、两族、镜像和两名独立敌人：12场避免绕远路前队向先到援军发起攻击，1200 tick内四名士兵存活、零损失与花费；12场对手虽直线近却必须长途绕墙，900 tick内实际摧毁目标基地、四名士兵存活、零损失与花费；12场仍统计隔墙真实射击，敌军实际打伤同侧基地边沿的探针工人。精确#300父版前24场决策失败，12个射程对照保持通过。

初版新场景漏设对手主基地防御，目标选择器先选较弱主基地但又拒绝其主基地兵力门槛，遮住了次基地案例；补上普通主基地防护塔。第一次射程对照把319.2射程的弓手放在目标实际射程外，12场正确允许进攻而测试失败；按真实结构表面与探针位置修正场景，并添加真实命中验证。均未改变规则、原测试或预算。目标先选不能进攻的主基地而忽略次基地的问题仍是独立未修正事项。
