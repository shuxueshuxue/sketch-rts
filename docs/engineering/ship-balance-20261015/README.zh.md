# 船只生命与造船术（规则 4）

基线：main `4804631c`（规则 3）；独立分支 `codex/ship-balance-20261015`。
用户明确授权：所有船只基础生命 +25%；码头新增三级造船术，费用 500/1000/1500 金，每级增加 1/3 生命上限及 1/5 移速；船只不受兵营攻防科技影响。

## 实现

七种船型全部调整：运输船 270→337.5、战舰 320→400、重型舷炮舰 740→925、巡海快艇 110→137.5、臼炮舰 260→325、焚潮舰 340→425、远洋运兵舰 480→600。战斗单位最终生命按既有引擎规则取整，保留原始基础数值计算科技与星级。

两种族的码头均可研究 `shipbuilding`，快捷键 N（避开臼炮舰的 B）。每级相对新基础值累加，生命倍率 4/3、5/3、2，移速倍率 1.2、1.4、1.6。研究时间沿用强化护甲三级时长 40.5、52.5、66 秒。保留其他科技原有适用范围，独立机动科技与造船术的移速倍率各应用一次。

兵营及灰烬锻炉的武器训练、强化护甲均排除船只，陆军效果保留。研究完成作用于现役船只，后续新造船使用同样属性；升级延续已有机制，增加的生命上限补入当前血量，保留受伤缺口。

规则编号升级为 4。旧回放及联机规则不允许跨版本模拟；旧存档可以显式导入当前规则：造船术初始化为零、重算船只属性、保留当前血量（只按新上限封顶），不修改源存档。中立船只也更新基础生命上限。新存档正常往返保留科技和船只状态。
