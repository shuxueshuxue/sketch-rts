# 快捷键规范（草案，待 owner 确认）

适用范围：对局里每一个可以点的按钮，以及镜头、编组、选择这些全局键。
按钮的冷却态和进度见 [进度显示规范](../art/progress-display.zh.md)。

## 0. 现状（main 001f3bfa 盘点）

- **分发方式**：只有一个 `onKeyDown`（`main.ts`）。
  - 数字键先交给编组和物品。
  - 其余字母去 `commandButtons` 里找"可见且 hotkey 相同"的第一个按钮。
  - 同键的两个按钮里，排在数组前面的赢，后面那个用键永远按不到。
  - 按钮上的 `data-hotkey` 只是显示，不参与分发。
- **全局键**：
  - 方向键平移镜头；W/A/S/D 也平移，但只在没有按钮占用这个字母时才平移。A 永远不平移。
  - 1–9 调编组，Shift+数字存编组。
  - 1–4 在对应数字没有编组时，用该槽的物品。
  - Tab / Shift+Tab 切换选择组。
  - Esc 依次关装备面板、取消瞄准、退出子卡。
  - Enter 聊天。
  - Alt+A 切小地图敌我色，Alt+W 切风向。
- **同一屏的真实冲突**：
  1. 船厂 **C**：训练重型运输船和购买船炮同屏，购买船炮用键按不到。
  2. 船厂 **B**：训练炮击船和购买喷火器同屏，购买喷火器用键按不到。
  3. 选择里同时有单位和建筑、焦点在建筑上时：
     - 攻击移动 A、卸载 D 仍然可见，压住了建筑卡上的 A 和 D。
     - 被压住的是：箭塔营和余烬尖塔的弓手（A），城镇大厅研究"建筑耐久"（D）。
- **和全局键冲突**：
  - 任何可见的 W/A/S/D 按钮都会吃掉镜头平移，包括工人 W、战舰 W、武器训练 W、商店 W、老兵第二技能 W、卸载 D、建筑耐久 D、建造子卡里的马厩 S。
  - 结果是镜头能不能用 WASD 平移，取决于当前选中了什么。
  - Shift+A、Shift+B 总是弹出"需要单位 / 需要工人"，没有排队施令。
- **没有快捷键的可点按钮**：
  - 进船舱 / 回甲板。
  - 登船 / 收回跳板。
  - 被动老兵技能（aria-label 里留着空的"()"）。
  - 训练和研究进度按钮（点击取消）。
  - 选择栏里的组、船舱里的乘员。
  - 装备、船舱面板里的所有格子。
  - 小地图的两个开关（有 Alt 键，但按钮上没写）。
  - 对局菜单的按钮。
- **物品栏**：用 1–4，但和编组共用。某个数字存了编组以后，那一格物品只能点。

## 1. 原则

1. **按语义，不按位置。** 我们的指令卡是 8×2，不是 War3 的 4×3 网格；格子数量随单位变化，按位置记键会一直漂移。
   - 键取功能名里的字母，同一个功能在所有界面用同一个键。
   - 只有一类按钮按位置：一排同类货品，见第 3 节的商店和营地。
2. **字母只属于按钮。** 全局功能不占用裸字母键，只用方向键、数字、Tab、Esc、Enter、F 键，或带修饰键的组合。
   - 这样"按 W 会发生什么"只取决于屏幕上有没有 W 按钮，不取决于选中了什么。
3. **一屏一键一按钮。** 同一时刻可见的按钮里，任何两个都不能同键。用测试保证，见第 6 节。
4. **每个可点的按钮都有键**，或者明确写进"不需要键"的白名单，并写明理由。
5. **按键和点击等价。** 按钮不可用时按键也给同样的拒绝提示；冷却中按键提示剩余时间。

## 2. 全局键

| 键 | 功能 | 说明 |
|---|---|---|
| 方向键、屏幕边缘 | 平移镜头 | Shift 加速。**取消 W/A/S/D 平移**（待 owner 确认，见第 7 节） |
| 1–9 | 调编组 | 双击跳到编组 |
| Shift+1–9 | 存编组 | |
| Tab / Shift+Tab | 切换选择组 | |
| Esc | 关面板 → 取消瞄准 → 退出子卡 | 子卡里的"返回"按钮显示 Esc |
| Enter | 聊天 | |
| F10 | 对局菜单 | 新增；现在只能点 |
| Alt+A / Alt+W | 小地图敌我色 / 风向 | 按钮上补写这两个键 |
| Shift+指令键 | 排队施令 | 新增：Shift+A、Shift+技能键排在当前命令之后；现在会误报"需要单位" |

物品栏的键见第 3 节。

## 3. 各界面的键

### 单位指令卡：通用动作，所有单位卡固定

| 键 | 功能 |
|---|---|
| A | 攻击移动 |
| D | 卸载 |
| B | 建造（工人） |
| I | 装备 / 船舱 |
| J | 瞄准 |
| Z | 姿态 |
| G | 登船 / 收回跳板（新增） |
| E | 进船舱 / 回甲板（新增） |
| P | 学习老兵技能 |
| N | 下一个可学技能的老兵 |

- 技能键不能用上表的字母。现有技能键（H、U、C、X、R、J、L、K、B、F、V）里：
  - "踩踏 J"和"瞄准 J"不会在同一个单位上，可以保留；
  - "钉射 B"和"建造 B"也不会在同一个单位上，可以保留。
- 规则写成：**通用动作键优先**，技能只在不同时出现的前提下可以复用这些字母，由测试检查。

### 选择里同时有单位和建筑

- 指令卡**只显示焦点组那一张卡**。焦点在建筑上时，攻击移动和卸载不显示。
- 这一条修掉冲突 3，并且不需要给弓手、建筑耐久改键。

### 建筑卡

- 训练和研究的键取名字里的字母。同一建筑上不重复，由测试检查。
- 船厂的购买移到一个"购买"子卡，键 **U**。子卡里三样船装备按位置放在 Q W E，接收者是 O。
  - 这修掉冲突 1 和 2，也和商店一致。
- 加固塔升级 F、呼叫驻军下塔 U 保持。

### 商店、营地：按位置

| 界面 | 键 |
|---|---|
| 商店 | 货品按格子顺序 Q W E R T Y U I；接收者 O |
| 营地 | 雇佣 M |

一排同类货品没有自然的语义字母，按位置最好记。

### 物品栏

两个方案，待 owner 选，见第 7 节：

- **甲**：物品用 **Alt+1–4**，数字留给编组；按钮上写 `⌥1`。
- **乙**：保持 1–4，有编组时编组优先（现状），按钮上那一格不写键。这一格进白名单，理由是"由编组占用"。

### 不需要键的白名单

| 按钮 | 理由 |
|---|---|
| 选择栏的组 | 由 Tab 切换 |
| 船舱乘员 | 一个个点选，数量不定 |
| 装备 / 船舱面板里的格子 | 拖放操作，面板打开时键盘只认 Esc |
| 训练 / 研究进度按钮 | 点击是"取消"，误按代价大，故意不给键 |
| 对局菜单里的按钮 | 菜单内用 Tab / Enter |
| 被动老兵技能 | 不可施放，只是展示 |

## 4. 显示

- **按钮**：
  - 右上角写键，现有样式不变。
  - 带修饰键的写成 `⌥1`、`⇧`。
  - 没有键的按钮不画角标，aria-label 不留空括号。
- **鼠标提示**：标题后面写 `(H)`，这一部分已经有了。
- **子卡**："返回"写 `Esc`。

## 5. 按钮状态（补进进度规范的部分）

| 状态 | 画法 | 按键 |
|---|---|---|
| 可用 | 正常 | 执行 |
| 冷却（技能、物品、招募、补货、跳板） | 扇形 + 剩余时间，不变暗（进度规范 §4） | 提示"X 后可用" |
| 不可用（缺金、缺人口、等级、没有目标、不在范围、没有可接舷的船） | 整体降到 .48 + 中部文字带写原因 | 提示原因 |
| 冷却又不可用 | 只画冷却 | 提示剩余时间 |

- 物品和接舷按"冷却 / 不可用"两行处理。
  - 接舷现在只有冷却；"没有可接舷的船"要补成"不可用"。
  - 物品没有"不可用"的情况：需要目标时进入瞄准，所以不需要文字带。

## 6. 测试（改代码时一起加）

- 把每个指令按钮的定义抽成一份清单，每一项写明：键、可见条件（哪些单位、建筑、站点、子卡）、是否在白名单。
- 测试遍历所有界面：
  - 每种单位、建筑、站点；
  - 每个子卡；
  - 混合选择。
- 对每个界面断言两件事：
  - 可见按钮里没有重复的键；
  - 每个可见按钮都有键，或者在白名单里。
- 再加一条：任何按钮的键都不能是全局键（方向键、数字、Tab、Esc、Enter、F10）。

## 7. 需要 owner 决定的

1. **取消 W/A/S/D 平移镜头？** 推荐取消，只留方向键和屏幕边缘。理由：现在它取决于选中了什么，不可预期。
2. **物品栏用甲（Alt+1–4）还是乙（数字，编组优先）？** 推荐甲：物品永远有键，编组永远不丢。
3. **船厂购买放进"购买"子卡（U）？** 推荐放。
4. **新增 F10 菜单、Shift 排队施令？** 推荐都加。
