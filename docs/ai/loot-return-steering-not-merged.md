# Loot 回程 steering：不合并（2026-10-18）

PR [#523](https://github.com/shuxueshuxue/sketch-rts/pull/523) 关闭、不合并；保留 `codex/loot-return-arrival` 分支、[完整报告](loot-return-steering.md)、[逐局结果](loot-return-steering-results.json)和[原始证据指针](loot-return-steering.evidence.json)。最终原生实现为 `76303b36`，对照 main 为 `710986b1`。本轮不再收窄判定、调参数或优化性能。

## 决定依据

历史 ladder-18 ember 的 ashWarden 确实因两个 flow field 拼接后的 lookahead 捷径而持续折返；旧快照和真实浏览器右键都能证明，候选也能走到目标。但该快照来自旧版本 `41c9c208`，当前 main 的同种子完整对局已不再出现这条旧轨迹。

两组 seed 各跑 main/candidate 240 局，共 960 局。可视跨 field 捷径首格非下降、进入后原 lookahead 立即反向的调用分别从 **7500、7025 降到 0**，但当前 main 的 **480 局里，这类事件后出现 ≥60 秒振荡的次数本来就是 0**。因此机制计数下降不能折算成当前版本可量出的长振荡收益。

| seed | 胜/负/平 main→candidate | 己方 stall@10 均值 | 己方 stall@60 均值 |
|---|---|---|---|
| v5-final-1 | 162/55/23 → 163/54/23 | 1.149 → 1.785（+55.4%） | 0.118 → 0.208（+75.7%） |
| v5-final-2 | 147/64/29 → 149/64/27 | 5.309 → 6.265（+18.0%） | 1.116 → 1.465（+31.3%） |

stall 单位为每局平均 unit-minutes。两组 seed 的 stall 都朝同一方向变差，增幅约 **18%–76%**。候选的 259 个 ≥60 秒振荡逐例做同姿态对照，都是 main 也有的拥挤卡点；这只能排除新规则直接制造这些卡点，不能排除新轨迹更频繁地触发已有卡点。系统性的 stall 增量不能当成洗牌噪声。

同一 A100、同一 CPU 的 `large-battle-think` 主体耗时 **35.991 → 38.482 秒（+6.92%）**；其他性能口径及原始批次保留在完整报告。胜场仅增加 **1、2 场**，处于对局轨迹变化的噪声范围，不能抵消 stall 与性能代价。因此本轮不合并。

## 保留与重启条件

以后如果在当前版本的真实对局或玩家反馈里再见到长时间折返，就从 **`76303b36`** 重新开始，并且先查清 **stall 为什么会系统性上升**。

`mountedEscape` 空候选也暂缓。960 局终验中 main 和最终版都没有触发；中间版的调用栈与快照已保留在原始证据中。本轮不继续诊断或修复，lane 停止。
