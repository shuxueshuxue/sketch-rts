# 实际入侵与潜在改道的只读风险事实

`createThreatIntentQuery` 将原生攻击对象、非避战接近订单和站点内敌对驻留归给至多一个实际站点。其余站点保留潜在改道，绝不把几何最早到达解释为已经来袭。避战移动和正在打野的订单不能充当进攻本站的证据。

`defenseThreatScenarios` 按原实际目标分组，以改道 ETA=e、移除当前报价队伍后的其他可用援军 ETA=r 估算 r/(e+r)。没有其他援军时为1，援军 ETA 未知时保留未知。调用者必须提供移除本组后的响应，不能用这组自己已到岗的零 ETA 消掉自己的价值。实际入侵全额，潜在改道枚举互斥情景；每个情景用真实整组敌力，不以概率乘兵力捏造平均军队。最多6个潜在组、64个情景；超限明确unknown。

`defenseProtectionValue` 对每个情景分别比较“本组+静防”和“只有静防”的保护价值，再取期望。实际兵力进入P，安全余量由方法出发需求承担。零报价兵力带来的额外保护恰为0。

E01回归锁住：8名实际攻击前矿1166的敌军不再同时作为主城实际入侵；潜在改道只付对应概率的价值。这里只交风险事实和纯估值接口，尚不宣称分配器最终排序或行为验收已经通过。
