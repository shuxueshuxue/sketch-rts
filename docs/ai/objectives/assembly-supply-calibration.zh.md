# 集结条件供给的原生联合样本

正式数据仅使用 `assembly-supply-646-joint-live-tail-v2-eeac1238909c`。来源模型 gzip SHA256 为 `a999df9960db53aa65276b6fcf4b07a948f5e48c491b83be5d4bf951d86c85bb`；216 个固定窗口用于全局 cell 拟合，另 30 个真实任务 anchor 仅验证，不加入训练。地图和 owner 只作来源证据，不作选择特征。

相同版本、种族、阶段及生产建筑 kind 组成按全局优先级选 cell，至少跨两图。所有情景等权且保留零供给质量；资源反事实在选定同一个完整 cell 后删对应生产列，不重新挑样本。同 kind 多厂无可核身份映射时明确 unknown。库存按原始 300 tick 采样作阶梯观测，不线性插值，不将支持端点之外延长成已知零或常数。

每点保留真实成员的 HP、maxHP、武器伤害/冷却/范围、速度、等级及来源 ID。紧凑文件只去重完全相同的成员 profile；打包脚本核每点总量，独立测试重新调用原生 combatRating 核全部 profile 和点。来源 ID 不是未来实体 ID，未来评估不能把它写进 lease、出生记录或目录阵亡身份。v1 出生等价保留量仅供诊断，不回填正式 force。

旧经济供给映射到本次生产 lane 和同陆块 post：扣除源样本已付管线，再按当前已付管线和原生 post 路线平移。每列保留源 epoch、原支持期、当前管线和 routeTicks，不能把当前生产工作完成当作合法出生或到岗。这里仍是观测可用兵池的条件供给估计；post 路线另取共享事实，现场阻塞和后续争用须另验。

固定窗口 LOMO 各时长指标保存在同目录 validation 数据。真实 30 anchor 中只有 20 可评，120 秒新增 1 自然战力的条件时间 MAE 约 29.55 秒，偏差 −20.92 秒，表现偏乐观；先保留此限制，不据此修参数，也不宣称整组到岗或夺岛概率已经校准。正式 reader 接线、6144 总账本和连续行为须另验。

出口可达性由 native landSpawnPoint 的规划 callback 读取当前 think 的共享查询；原生执行省略 callback，保留原路径。规划不会采用进程中已暖的原生可达答案，callback 未发布时直接 pending，不回退为物理堵塞。请求每次 think 重新注册，已分配及前 K 候选的该类 pending 目标在同一 6144 账本中提升服务优先级。旁表保留稳定 producer/kind/rally 身份和几何版本、pending/known 及实际请求点；身份不含当前 tick 或移动成员坐标，连续运行可据此核 pending 次数、最长持续时间和几何失效，不将缺样本报告为零等待。受控关闭 gate 的回归从零预算 pending 开始，后续共享额度与 JSON 恢复中在 165 tick 内公布；这不是两局或全图时延保证，仍须连续统计。
