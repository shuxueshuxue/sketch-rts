# 正式世界渲染与资源载入

建筑和六种船只使用实时 GLB 模型；人物仍采用原有画风，绘制到带透明裁切的直立卡片上。地形由 Canvas 绘制，实体共享 WebGL 深度，选框、血条、命令反馈等由前景 Canvas 绘制。没有 WebGL2 或图形上下文失败时保留 Canvas 路径。

## 坐标与职责

- 模拟拥有地图位置、船体朝向、甲板位置、武器炮口、弹道与伤害。渲染只读取快照。
- 地图 `(x, y)` 对应 GPU `(x, elevation, y)`。导出时将 Blender 的纵向反射并烘焙，修正面绕序；运行时实例没有负缩放。
- 正交相机补偿俯视角，地面投影与原地图完全一致。人物保持竖直，足点落在实际甲板高度；船帆、炮和人物接受同一深度判定。
- 选取使用模型射线及人物透明像素；甲板命令将屏幕点反投影到甲板平面。框选使用显示出来的人物位置。
- 船体与挂载武器独立实例化，使用模拟中的炮位、朝向和损坏状态。船体没有额外瞄准系统。弹丸外观由发射时保存的攻击类型决定，停止收到快照时最多插值一步，不提前越过命中时刻。
- 同种模型、材质、队色和人物姿态合并为实例；人物纹理按使用情况淘汰。模型、材质和实例对象可释放。

## 分阶段载入

`bootstrap.ts` 先显示小型载入页，再根据构建时生成的 `resource-manifest.json` 读取界面代码、样式和字体。首页只准备当前场景；切换场景时准备该场景。点击开始比赛或进入正在进行的房间后，再准备所有对局模型和常用作战音效，完成后才创建或连接对局。

进度来自响应流的实际字节数。模型和图片带内容版本，目录和音效清单重新验证；未知大小明确标为待确认。单次最多四个请求，同一资源跨阶段共享下载和解码结果。记录页显示大小、耗时、已复用大小及失败项；入口位于设置的音效区域下方，在折叠的“资源与性能”中。这里的大小是解压后的资源读取大小，包含浏览器缓存，不代表本次压缩网络流量。

重试保持原始启动或开局调用等待，资源准备成功才继续。不会出现重试载完后无法开局的半启动状态。

图形上下文丢失或渲染失败时，Canvas 资源按当前阶段和当前场景准备；首页不会因此提前载入遭遇战。恢复读取最近一次显示的快照及建筑模型，较早的异步准备不能重新启用已失效的场景。切换世界会立即清空旧选取和甲板反投影状态，下一帧绘制后再启用。

GLB 共 31 个；实际资源字节数与载入阶段可在设置中的资源诊断中查看。三维模块在场景准备时载入；UI 头像与世界共用已解码的模型，没有独立头像图片。缺少 WebGL2 时，世界使用 Canvas 回退，UI 仍可从当前 GLB 生成一致的头像。旧图集不会进入任何载入阶段。

## 重建与验证

1. `python3 tools/art/build-ships.py --blender <Blender>` 生成六种可编辑船体。
2. `node --import tsx tools/art/export-building-geometry.ts` 导出建筑面数据。
3. 在 Blender 后台运行 `tools/art/export-world-gltf.py`，输出 `public/art/world3d/`。
4. 头像直接从当前 GLB 几何生成并缓存，复用世界模型的下载与解码，不另行生成图片。
5. Vite 构建自动生成资源大小与内容版本目录。

新增验证覆盖所有真实 GLB、相机投影与甲板反投影、透明像素选取、人物颜色材质、实例合并、弹种区分、延迟快照、流式字节进度、并发队列与重试。CPU 场景测试只替换 WebGLRenderer，仍使用真实模型、材质、相机、射线和人物绘制；这不是 GPU 画面或 GPU 性能验收。云浏览器已用 SwiftShader 跑通正式 WebGL2，覆盖 200/1000 人与六船型甲板场景，记录见[系统方向与战斗面板验证](../reviews/system-directions-and-hud.zh.md)。软件渲染不能代表真实显卡帧率，硬件性能与完整遮挡仍需在物理 GPU 上验收。

## UI 与资源清理

船只和建筑的旧 PNG 图集、深度图、队色遮罩、旧船头像和早期单船 GLB 已删除，离线建模工具也不再生成它们。实时渲染只保留地形、实体和标记三个必要图层；Canvas 回退使用物理船形与已有矢量绘制，不读取旧图片。头像从当前 GLB 生成小型缓存，不创建额外 WebGL 上下文，不参与世界渲染循环。

头像缓存统一管理模型版本、画布像素密度和实际 UI 尺寸。选中卡、训练、队列、船员和装备人物按可见边界适配。共享材质与控件位于 `game-materials.css`、`game-ui.css`；首页和对局内设置复用 `sound-settings.ts`。物品提示作为浮层显示，不占布局行；隐藏的资源记录不持续重建列表。
