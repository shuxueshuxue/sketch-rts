# 单位悬停光标

本轮按用户反馈恢复光标原形状：未锁定时是细十字，锁定时是原有的 18 px 圆环与中心点。己方绿色、盟友青色、敌方淡红色、中立金色，只改变颜色；同一模式下全部关系的几何完全相同。原生热点居中 `(12, 12)`，锁定热点居中 `(9, 9)`，锁定坐标统一取整，避免悬浮前后半像素偏移。命中、队伍关系、攻击瞄准和建造优先级保持原规则。下文及原截图记录的是上一版形状验收，不能作为本轮外观证据。

## 上一版验收记录

普通检查模式下，光标按当前玩家、目标拥有者和实际队伍显示关系：己方绿色盾牌、盟友青色双环、敌方淡红菱形、野怪或中立地点橙色圆环。形状与颜色共同区分关系，敌方提示仍表示检查；单位无法攻击船体时也可检查。死亡、进入船舱、过期 ID、空地和无玩家视角会立即清理关系提示。

2D 与 3D 共用实际命中 ID 和关系计算。未锁定鼠标时使用小 SVG 原生光标，热点为箭头尖端 `(4, 3)`；锁定鼠标时使用生产虚拟指针的同一 32×32 图像和相同热点。攻击瞄准保持十字，建造保持放置光标，不被单位关系覆盖。打开菜单和离开单位会清除旧关系图像。

悬停帮助函数 10 项测试、既有单位关系 18 项测试通过，覆盖甲板单位、建筑、实时队伍变化、死亡和舱内目标、观察者、命令模式、部署前缀和热点。相关 UI 定向测试共 34 项通过，类型检查通过。

真实浏览器在 3D 和 2D 各通过 12 项输入检查，页面错误均为 0。通过实际地图按钮进入单人配置并点击开始，使用实际单位、原命中和渲染通路；3D 记录到 46 次真实模型命中。检查涵盖四种原生关系光标、空地复位、攻击和建造模式、真实鼠标锁定后的己方/盟友/敌方图像与准确热点、锁定下攻击指针和菜单复位。验收固定测试单位并限制动画频率，只验证功能，不作 FPS 结论。

## 可见中立对象的遮挡与命中成本

后续修复将单次悬停合并为一次模型命中。可见单位、建筑、营地和商店的命中 ID 统一决定目标；只有模型命中为空时才使用原地面优先级。营地或商店覆盖住己方士兵时保持中立光标，避免通过屋顶命中被遮挡的士兵。死亡、入舱或过期的可见对象也不继续向后解析另一个目标。

目标解析 7 项、光标 10 项和关系 18 项定向检查通过。新的真实浏览器记录包含营地、商店各一次原生悬停和一次锁定指针悬停，共四项通过、页面错误为零。模型命中确实指向中立屋顶，而同位置独立地面查询指向被遮挡己方士兵；营地和商店的两个连续实际绘制帧均各执行一次生产模型命中。原生路径核对样式和资源，锁定路径核对生产指针图像。实际屋顶遮挡截图不包含操作系统光标像素，也不用于 FPS 测量。
