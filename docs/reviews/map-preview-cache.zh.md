# 地图预览缓存

命名双岸地图的物理座位与外交独立后，原预览缓存仍把队伍写进键，每次修改联盟都会重建相同的地形、出生点和初始实体。现在这类地图按地图、有效种子和有序玩家 ID 缓存物理快照，外交改变只创建新的快照外层与队伍字典。其他地图仍把队伍纳入键，保持原生成规则。

缓存最多保存 24 张物理快照，命中会更新使用顺序，超过上限淘汰最早未使用项。缓存内部快照递归冻结；调用者每次得到独立的快照外层、外交字典和座位数组，修改自己的外交或数组不会污染后续预览。地形、实体和静态统计只读共享。实际使用方只有预览绘制与地图资料展示；地形绘制缓存保存在外部 WeakMap，不在地形数据上写状态。

7 项定向测试和类型检查通过。对 3:1、自由混战及重新组合的 2:2 联盟，逐个生成真实游戏完整快照，验证缓存视图完全相等，并验证唯一差异为外交字段。还验证改种子、换座位顺序、换玩家 ID 和非双岸地图外交不会复用物理对象；尝试修改共享实体、地形、资源数组或统计被阻止。24 个小型非生成地图验证缓存上限，淘汰后重建快照的值保持相等，不用额外生成 24 张大型地形。

此改动消除了联盟编辑时的重复地图生成，并复用了原地形绘制缓存；没有以这些功能测试作 FPS 或耗时比例结论。
