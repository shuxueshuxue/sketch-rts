# 自动房间流程与浏览验收兼容

- 地图列表点击立即创建单人配置房间；四个浏览脚本通过实际地图按钮进入配置，取消对创建表单和提交步骤的依赖。
- 单人房间由浏览器运行。服务端列表不得包含该房间；本地房间列表应允许原用户返回。刷新配置 URL 重新创建房间，验证地图、种子、房名、队伍、种族和电脑席位保留，不把新的本地房间 ID 当成丢失状态。
- 多人配置使用真正的服务端房间 ID。验收实际邀请另一浏览器用户加入空位、准备并等待房主；原有服务端列表、刷新重入、比赛刷新重连和关闭清理检查继续使用这个 ID。
- 使用服务端快照、重置、命令和同步接口的玩法验收，先通过模式按钮转为多人，再恢复电脑席位。比赛单位、电脑对手和原玩法断言保持原设定，未把本地房间伪装成服务端房间。
- 非地图池测试场景继续通过现有服务端地图接口设置；地图池场景仍由实际地图选择按钮进入。独立玩法场景导航到首页文档，比赛刷新重连场景继续使用刷新。
- 布局选择器跟随已存在的地图资料左、席位右和独立页脚结构；保留不重叠、单行紧凑席位、地图名和席位数、控制器选项、唯一关闭按钮及页脚位于列表后方的检查。
- 研究操作先通过真实小地图定位测试兵营，再以原生鼠标选中；不依赖比赛初始镜头恰好对准固定世界坐标，仍验证该兵营 ID、研究按钮、队列和进度。
- 输入、指针锁和几何测量使用 `.game-canvas`，不把前置的隐藏地面画布当成游戏输入层；像素验收按显示顺序合成地面、角色与游戏画布，保留原哈希、着色和图像变化判据。
- 原指南针队伍名按已有 `roomTeam` 规则使用实际下拉选项：north/south/west 对应 team-1/team-2/team-4；仍检查实际队伍分配。双岸地图遵循现有主线的外交独立规则：四座位完整时允许 3:1 对战，全部同队和存在无人加入的开放座位时禁止开始，恢复对立队伍及电脑座位后允许开始。等待座位编辑控件重新启用，避免把请求过程中临时的禁用状态当成最终开始规则。

结果页场景仍使用三个原攻城单位，由正式出生计算在实际玩家基地附近分配身体可完整放入的空位；明确给出攻击该基地的初始命令，单位自行接近至原近战射程。原固定坐标已经远离新的基地，idle 单位也会被电脑的集结调度带走，无法稳定触发这段 UI 结果页验收。数量、类型、血量、伤害、电脑设定和 4800 tick 上限保持原设定。研究进度仍用原 5 秒时限等待非零进度，不把刚出现的 0% 按钮当成已经推进。

完整 `e2e-room-flow.mjs` 浏览函数已在 Chromium 的受支持 2D 回退模式通过，使用真实鼠标、HTTP、SSE 和比赛 WebSocket。仅屏蔽开发服务器 HMR，未节流 `requestAnimationFrame`。原 5 秒等待预算和结果页 4800 tick 上限保留；覆盖单人配置 URL 刷新、多人的真实访客加入准备、服务端房间重入、比赛权威快照重连、原生选中实际兵营、研究进度、结束结果、指针锁释放、双岸外交编辑和关闭清理。指针锁释放使用原结果页生命周期的受控锁状态场景，实际原生指针锁和光标验收另有记录。控制台及页面异常均为零；导航和关闭期间三条 SSE 请求取消属于正常释放。

权威刷新后的客户端快照为 tick 14，包含测试兵营；原生点击选中 `ui-research-barracks`，研究显示 1% 和非零进度宽度。双岸地图显式种子曾使外交独立的物理岸位逻辑失效，导致 3:1 队伍的预览抛错并留下禁用控件；修复后，真实席位编辑与正式地图生成遵循同一规则。精简结果见 [automatic-room-flow-acceptance.json](../../assets/menu/automatic-room-flow-acceptance.json)。本轮是功能验证，其他正确性工作并行执行，不能据此比较性能，也不作为 3D 渲染验收。

五个脚本的 Node 语法检查及四段内嵌浏览函数展开后的独立语法检查均通过。`e2e-brutal-spec.mjs`、`yatu-player-loop.mjs` 和 `room-sync-yatu.mjs` 只完成自动建房兼容改动与这些静态检查，未运行其完整端到端套件；其中原有的旧 HUD 图标和固定像素规格判据仍需按对应验收范围复核。

预览缓存随后改为共享深冻结物理快照、每次返回当前外交包装。短实际浏览验证再次自然点击双岸地图，原生编辑 3:1、自由混战及交换成员的 2:2：每次控件解锁并可开始，真实 512 × 512 预览均完整绘制，包含 5094 种像素颜色，像素哈希均为 `64d06aef`，物理地图对象保持同一引用且深冻结，外交值及时更新。实际转为多人并点击开始后，比赛保留双岸地图、四个座位、交换后的外交和与预览一致的基地位置；控制台及页面异常均为零。此短验收仍为受支持的 2D 回退及原 5 秒等待预算，未重跑完整结果与邀请流程，也不覆盖其既有证据。另存 [frozen-shore-preview-acceptance.json](../../assets/menu/frozen-shore-preview-acceptance.json)。
