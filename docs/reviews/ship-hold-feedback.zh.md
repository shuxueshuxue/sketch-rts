# 船舱与瞄准修复验收

炮位、船体示意图、船员卡和拖动目标共用同一套甲板投影。炮位使用绝对定位，船舱行高最多 55px，单行格子不再填满整个面板。

船员卡保留实际位置；拖动显示目标箭头，松开后发送普通移动命令。甲板边界和障碍由现有的物理位置投影处理。武器耐久在船舱、携行位置和已安装炮位持续更新，损坏的炮明确显示“无法射击”。窄屏保留耐久条和损坏标记，完整数值可从选中说明查看。

首页五艘船都带有士兵，部分农民通过实际甲板移动命令巡走。船体运动不会触发站立船员的走路动画。重复的按钮限制提示在通用提示入口去重。

野怪追击及受击响应范围由 520 提升为 650。船体不再拥有远程准星或模拟普通射击；每件安装武器拥有独立准星、射界和冷却。喷火主动攻击同样从实际炮位进行瞄准。

验证：249 个测试文件、2023 项测试通过，TypeScript 和生产客户端/服务端构建通过。浏览器检查了运输船、大型舰的炮位、巡海快艇单行船舱，以及 390×560、350×360 的紧凑布局；实际拖动船员可发出移动命令。

公开验收页：<https://lexicalmathical.com/sketch-rts/audio-packs/ship-hold-20261007/equipment.html>。使用真实面板与模拟逻辑，独立运行，不影响线上对局。

## 精简面板占位

去掉标题上重复的“军械”标签和装饰栏。单个人物不再重复显示人物选择器，船舱只显示容量标题；没有可操作人物时隐藏整个空人物栏。单页船舱不创建翻页控件，交换条件满足时不显示“通路畅通”。

面板改为按可见内容排版：未选择物品时，操作栏不占空间；选中后才显示实际操作，状态提示短暂出现后隐藏。窄屏分页切换移到内容上方，底部不再保留多个空行。默认人物页高度从 640px 缩为 480px，船舱页为 560px，仍受窗口高度限制。

精简版验收页：<https://lexicalmathical.com/sketch-rts/audio-packs/equipment-chrome-20261007/equipment.html>。已检查宽屏、390×560、350×360 的人物和船舱操作、单页快艇船舱及大型舰炮位。50 项装备、甲板和投影回归检查、TypeScript 和生产构建通过。
