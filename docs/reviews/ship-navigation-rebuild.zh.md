# 船舶导航重做

这次针对两种实际体验重做：普通移动在路点前停船、转向、再起步；远处点击正在航行的敌船后，不断重建路线并反复打舵。改动前对照版本为 `09be683`。

## 航海依据与游戏取舍

实际阅读了 Luce《Text-Book of Seamanship》的迎风操纵章节、Day《On Yacht Sailing》的迎风和换舷章节，并与 US Sailing、Raymarine 和自动舵手册交叉核对。[阅读记录](sailing-navigation-sources.zh.md)列出章节、原文链接及适用边界。保留动量、提前回舵、走有效长舷、明确完成一次避让，都是影响实现的原则；移动目标拦截及参数是本项目的工程设计。

仍采用此前确认的 RTS 折中：不同帆装有不同近风性能；开阔水域自动抢航；风眼、狭窄水道和泊位允许有上限的低速辅助。没有引入潮流、侧漂、波浪或完整的索具动力学，不能用这套模型预测现实船舶。

## 分层职责

- **战术目标**：普通移动、跟随、接敌和靠泊分别处理。追踪船体身份，武器可以独立选择船员目标；最多预测六秒的目标运动。接战采用进入/离开距离迟滞，移动时匹配速度，静止后制动并选择有射界的站位。
- **航程规划**：开阔水域使用符合船型转弯半径的前进圆弧接切线；受地形限制时使用已有的整船朝向搜索。近处泊位、倒船和支点转动保留精确执行。远处另一艘船的旧位置不会让普通移动全程变成靠泊。
- **迎风航段**：优先检查能接到目的地的两条长舷；水域不足时检查较短的合法航段。动态目标小幅移动时保留当前舷侧；穿风动作完成前不随每次目标更新重新择舷。部分抢航结束后从新的位置接续路线，不倒追出发时的圆弧。
- **舵手**：前视点沿参考线前进，输出同时发生的推进和转向；保存转向速度并限制变化速率，靠近目标航向时逐渐回舵。普通中间节点不要求精确停船，最后一段按余距和转弯能力减速。
- **交通避让**：根据相对速度预测相遇时间与最近距离，提前作出明确的右让动作；通过后从当前位置重接下一航点，避免为了回旧中心线再多转一个弯。所有意图仍受整船碰撞检查约束。

实际运动统一经过 `advanceShip` 的推进、转向、地形和船体扫掠检查。航路、转向速度、抢航选择、避让承诺及追踪状态均属于可序列化仿真状态；没有依赖客户端帧率或真实时钟的控制器缓存。校验和规则升至版本 12。载入旧版本存档时保留船体位置、动量和订单，清除缺少精确航段标记的旧路线，在下一 tick 重新规划；当前版本存档继续原样恢复控制器状态。

## 验证与复看

[人工回放验收](ship-navigation-visual-review.zh.md)说明观察到的问题、修复后的轨迹和对照数据。回放来自真实玩家指令及 `stepGame`，不是手工绘制的预期轨迹。测试同时检查到达、停走、快速反舵、无意义倒船、船体碰撞及存档恢复的一致性；到达时间通过并不替代肉眼检查。

[之前的连续转舵记录](ship-guidance.zh.md)描述早期控制器，保留作历史对照；其算法参数和测量值不代表本次实现。

最终检查：307 个测试文件、2611 项测试通过；`npm run build:production` 完成客户端与服务器构建。87 场矩阵的 75 个点目标全部到达，整批未记录船体穿岸或重叠；其中 44 项航行质量用例进入自动回归。完整[逐场指标](art/ship-navigation-metrics.json)保留基线 commit 与冻结仿真 bundle 的 SHA-256。

两个旧时间上限随精确操纵更新，并补上航程和总转向上限：狭窄海岸的船厂出航由约 45.1 秒变为 52.7 秒，验收预算改为含建造的 60 秒，同时要求航程小于 800、总转向小于 300°；接岸接人实测 25.85 秒，预算从 25 改为 30 秒，同时要求航程小于 300、总转向小于 180°及逐 tick 整船安全。没有放宽实际到达、登陆或碰撞条件。
