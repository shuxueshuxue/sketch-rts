# 选择与悬停标记的真实遮挡

选择圈、悬停圈和建筑方框现在属于地面／甲板层。它们保留友敌颜色和选择较粗、悬停较细的语义，同一个目标同时选中和悬停只画一个标记。血条、持续 buff、指令反馈和 HUD 保持原有表现层。

## 绘制路径

2D 将所有陆地单位、船形轮廓和建筑占地方框放到一轮 ground marker pass，之后再画任何陆地单位或建筑。因此邻近单位的圈也不会盖住先画的人物。每艘船先画船体／甲板，再一次画全部船员的甲板圈，再画桅杆、炮、旗和全部船员。桥上的圈使用实际接舷桥的位置和高度。

3D 将标记从最上层 Canvas 移到实际地面、甲板或桥面上的实例化平面。材质开启深度测试、关闭深度写入；模型与 alpha-tested 人物卡片通过原来的深度缓冲自然遮挡标记。没有擦除半个圈、手画遮挡遮罩或改变模型透明度来模拟效果。建筑沿真实网格占地画方框；船按真实 hull 轮廓描边，仅应用一次船体缩放；甲板船员沿实际高度画椭圆；桥上的圈平行真实桥坡并沿桥面法线微抬，避免穿进桥板。

标记使用一个共享材质、实例化缓冲、复用圆／方 quad 与各船型 hull 几何；只有选中数量超过容量时才增长缓冲，不为每个单位或每帧新建 GPU 对象。它们不参与阴影和单位 picking。取消选择后隐藏，reset 清除当前实例，dispose 释放所属缓冲、几何和材质，不影响共享船模。

## 验证

定向检查覆盖全部地面标记早于所有重叠人物／建筑、HUD 血条和持续状态仍存在、100 次 hover 变化复用 GPU 对象、容量增长保留已有单位、重复 dispose 和桥面坡度。`tsc --noEmit` 通过；三个定向测试文件共 31 项通过，新增真实桥面矩阵专项也通过。

实际 Chromium WebGL2 / SwiftShader 使用生产 `WorldPresentation` 三层绘制路径。冻结场景包含重叠的两个士兵、第三个士兵和建筑，以及运输船／远洋船、重叠船员、实际已经架起的接舷桥。比较真正深度测试的画面、同一场景临时关闭 marker 深度测试的正对照、以及没有 marker 的同一场景：

| 场景 | 实际可见的标记差分像素 | 被模型深度遮挡的差分像素 |
| --- | ---: | ---: |
| 陆地人物 + 建筑占地方框 | 1976 | 1193 |
| 两船 hull + 甲板／桥上船员 | 2493 | 5131 |
| 仅甲板／桥上船员（排除 hull 的贡献） | 149 | 1248 |

生产标记的深度测试始终开启；临时关闭仅发生在审查的正对照中，用来证明上半弧和模型相交处确实被 GPU 深度挡住。两种实际渲染模式均无浏览器异常。该检查证明当前选择标记的位置和遮挡，不作为 GPU 性能跑分。
