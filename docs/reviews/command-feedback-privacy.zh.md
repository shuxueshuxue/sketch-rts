# 命令反馈只属于发令玩家

右键地面、指定攻击、排队命令、采矿、跟随、集结和走近后施法的落点圈是玩家的操作确认，不是公开战场事件。现在这些确认记录发令属方，客户端只在明确的当前玩家与该属方相同时绘制；同队共享视野不共享操作确认。缺少属方的存档反馈默认隐藏，不从坐标、目标属方或当前检查对象猜测发令者。

该规则由 [`command-feedback.ts`](../../src/client/command-feedback.ts) 集中定义，普通 2D、3D 上层 Canvas 和独立效果绘制入口使用同一策略。筛选只发生在呈现层，模拟和存档中的效果继续存在；不会删除造成持续伤害的世界效果或改变战斗判定。

## 盘点与分类

| 链路 | 处理 |
| --- | --- |
| `move / queuedMove` | 地面移动、跟随、卸载目的地、集结和走近施法的确认均记录实际发令玩家，仅本人显示。 |
| `attack / queuedAttack / attackTarget / queuedAttackTarget` | 攻击移动落点和指定目标确认仅本人显示；不隐藏真实枪炮、近战命中或伤害动画。 |
| `mine / queuedMine` | 采矿确认仅本人显示，金矿和工人实际行动保留公开。 |
| `repair / queuedRepair` | 没有 `unitId` 的工具/命令确认属本人；带真实工作者 `unitId` 的修理工作脉冲保留公开，继续驱动工人动作。不能一律隐藏同类型的工作效果。 |
| `board / unload / boardingBlocked` | 完成或失败提示的圈、叉与收据仅本人显示；船体、人员移动、已架设的接舷桥与真实甲板战斗保持公开。 |
| `itemReceived / goldBounty` | 收货提示及金币文字属本人，不改变实际物品、余额、击杀或公开单位呈现。 |
| 已付费地基 `build` | 这是建筑实际创建事件，原效果绘制入口跳过其工具图标；建筑本身保留公开。未创建建筑的计划草图原本已按当前玩家筛选。 |
| 集结旗与引导线 | 只有本人明确选中的生产建筑显示。检查盟军、敌军或中立建筑不会显示其旗帜；不能只判断“已选中且可生产”。 |
| 瞄准目标线与准星 | 世界绘制入口已有 `unit.owner === viewer` 限制，检查或选中另一方单位不会授权其目标线。 |
| 本地建造、攻击移动、瞄准、技能和冲锋预览 | 来自本客户端的 `commandMode`、鼠标和本人选择，未从其他玩家的输入同步。冲锋范围只读取本人可发令单位。 |
| 小地图 | 不绘制共享 `WorldEffect` 或其他玩家的目标路径；单位、建筑、风场等实际世界标记保留原规则。 |
| 3D 物理层 | 实际弹药、炮口焰、炮管方向、后坐力、人物动作和接舷桥仍正常绘制，不按发令属方隐藏。 |

治疗、召唤、诅咒、冲锋、震地、蛛网、嗜血、闪电、守护场、炮弹、火焰、命中和持续伤害等实际技能或战斗事件不属于私有命令确认，继续遵守原有世界绘制规则。对方真正发动技能时仍能看见；对方点击尚未到达的施法目的地时只能看见其实际移动。

## 观战与检查对象

`main.ts` 的 `matchViewer()` 使用房间中本客户端的玩家身份。观战时返回 `undefined`，因此普通观战和没有指定发令玩家的录制不显示任何一方私有操作确认；公开战斗效果不受影响。检查敌人、盟军或切换选择焦点不会改写玩家身份，也不会把该对象的属方当成私有反馈视角。房间身份真正变化时，策略按新身份即时重新计算，不缓存上一位玩家的允许结果。

## 验证

[`command-feedback.integration.test.ts`](../../src/client/command-feedback.integration.test.ts) 用真实 `issuePlayerCommand` 发令，覆盖己方、同盟玩家和敌方的普通及排队移动、攻击移动、指定攻击、跟随、采矿、资源集结、远距及排队治疗目的地。每个实际生成的确认都验证发令属方、仅本人可见和观战隐藏；集结策略另外验证同盟、敌方、中立与缺少身份时不可见。

同一组测试确认敌方实际治疗确实恢复生命且效果仍公开；敌方实际修理确实增加建筑生命，工作脉冲继续公开，而工具确认保持私有。呈现筛选前后的完整快照和 checksum 不变。还覆盖缺少属方的旧反馈与即时切换视角。上述真实发令测试和集结策略测试合计 **2 文件 / 9 项通过**，未以纯类型名单的镜像测试代替真实效果构造链路。

最终完整回归、真实浏览器验收与部署检查在本轮汇总文档[海军与交互跟进](naval-followup.zh.md)记录。本策略管理呈现反馈，不是网络层隐藏仿真数据或新增战争迷雾协议。
