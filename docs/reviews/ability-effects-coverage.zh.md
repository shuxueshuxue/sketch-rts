# 技能施放与持续状态表现

本轮只修改客户端表现，不修改伤害、冷却、持续时间、目标数量或战斗机制。技能来自 `ABILITY_DEFS`，三星技能来自 `VETERAN_SKILLS`，持续状态来自实际 `Unit.effects`；冷却不会被画成持续增益。

## 覆盖清单

| 能力 | 施放表现 | 生效期间 |
| --- | --- | --- |
| 压制弩矢、燃烧喷口 | 沿用真实弩矢、命中和燃烧区域 | 定身蛛网、灼烧印记的身体火焰 |
| 治疗、余烬治疗 | 治疗符号 | 瞬时恢复，无虚构持续状态 |
| 召唤、灰烬之魂 | 召唤阵与实际召唤单位 | 实体本身可见，寿命由状态栏显示 |
| 诅咒、灰烬诅咒 | 诅咒符文 | 紫色游动符纹 |
| 冲锋 | 跟随骑兵的速度线和命中冲击 | 实际移动姿态 |
| 野怪践踏 | 扩散尘土环 | 受影响单位头顶眩晕星形 |
| 野怪蛛网 | 白色蛛网 | 定身网跟随受影响单位 |
| 野怪嗜血 | 红色施放环 | 红色上升箭纹，在施放闪光结束后继续显示 |
| 猎手减速、毒蛛中毒 | 沿用真实命中 | 足边冰纹／绿色滴形，持续到实际状态过期 |
| 三星战斗号令 | 金色扩散环与箭纹，施放脉冲约 0.9 秒 | 每个真实受益单位的金色箭纹，实际持续 6 秒 |
| 三星群体恢复 | 绿色扩散环与恢复符号 | 瞬时恢复，无虚构持续状态 |
| 三星心灵之火 | 蓝色扩散环与盾纹，施放脉冲约 0.9 秒 | 每个真实受益单位的蓝色护盾，实际持续 6 秒 |
| 守护卷轴 | 沿用实际守护区域 | 受保护单位的金色护盾和足环 |
| 协同作战、警戒互助、坚守阵线、行军领队、休养庇护 | 被动光环无虚构施放 | 来源的分段足环；实际受益者显示攻速／防护／行军／受伤恢复的紧凑图形。选中来源时显示实际范围 |
| 百战之躯、迅捷行动、沉着瞄准、测距训练、坚韧恢复 | 被动技能无虚构施放 | 防护图形；移动时的速度纹；选中时的测距环；受伤时的恢复符号 |

`curse / guardian / scorch / slow / stun / root / poison / bloodlust / protection / veteranBuff` 十类持续状态均有战场表现。灼烧是易伤印记，图形不意味着新增持续伤害。嗜血与号令按实际最强短时攻速层显示一个图形；较弱但尚未过期的状态会在强者消失后恢复显示。

## 可见性与开销

2D 与 3D 使用同一套状态绘制路径，锚点取角色实际绘制位置；3D 使用投影后的身体和顶部位置，船员使用甲板或接舷桥的高度。入舱、阵亡和过期状态不会留下图形。无常驻解释文字，减少动态效果选项会停止新增符号的漂移。

每个快照只建立一次状态缓存。光环候选通过空间桶查询，再由权威 `buildVeteranFrame` 验证队伍、距离和目标资格，不对每个单位扫描全场。缓存使用 WeakMap，旧快照可被回收；没有新纹理、模型、计时器或长期粒子对象。绘制前先剔除屏幕外单位。同时把单位／建筑逐个绘制时重复计算的战斗血条集合改为每次 `drawWorld` 计算一次，并用已有船只索引查船员所属船。

只有指令所属玩家可见移动、队列、采矿、攻击指令、登船等操作标记；旁观者和缺少归属的旧指令标记按不可见处理。敌方真正的治疗、施放和受击效果保留公开战斗表现。动画跟踪仍接收原始效果，实际维修工作动作不会被过滤。集结点也需要选中建筑属于当前玩家。

## 验证与复现

定向检查：

```sh
npx tsc --noEmit
npx vitest --run src/client/ability-effects.test.ts src/client/effect-renderer.test.ts src/client/world-renderer.test.ts
```

37 项通过。测试使用真实野怪攻击、三星学习和施放命令，验证施放者离开后状态仍存在、短施放脉冲结束后 buff 继续可见、实际过期后清除、盟友／敌方／半径／舱内／机械目标资格，以及较弱 buff 的恢复。Canvas 实际像素检查确认有状态时有图形、过期后无残影；另检查 3D 投影锚点和私有指令不会遮掉公开治疗。

轻量浏览器场景由 `scripts/ability-effects-review-scene.ts` 提供。运行 `npm run dev:static` 后，可在现有截图 harness 或浏览器控制台中导入：

```js
const { createAbilityEffectReviewScene } = await import('/scripts/ability-effects-review-scene.ts');
const fixture = createAbilityEffectReviewScene('veteranInnerFire');
```

可选场景：`slow`、`poison`、`stomp`、`web`、`bloodlust`、`veteranRally`、`veteranHealingWave`、`veteranInnerFire`。返回实际 `game`、首次生效的 `snapshot`、来源和目标 ID；将 snapshot 交给现有 `WorldPresentation`，镜头放在 `(640, 640)`，分别检查 3D 和禁用 WebGL2 的 2D。调用实际 `stepGame(fixture.game)` 20、40、121 次并重新 `snapshotGame`，检查施放脉冲结束、状态继续与实际过期。野怪场景关闭主动技能重施放；如需隔离持续状态，可移除来源和其余战斗单位，保留目标再推进。

另已在实际静态部署 UI 的 2D／3D 浏览器中检查号令、减速、中毒和独立过期，未出现浏览器异常。三星施法者已死亡或因视野变化不在当前快照时，仍按实际已发出的特征识别短施放脉冲，不会变回持续的大面积普通嗜血／守护圈。
