# 船队、扩张与游戏界面

本次把装备面板、战场命令和设置改为铁框、内凹格位与统一材质，删除互相覆盖的旧战场皮肤。装备操作沿用虚拟鼠标，原生选择框才暂时解锁；编队号码改为单位右下方的白色细字。

六种舰船用不同帆装、舱室、货舱和炮口区分；选中舰船或其船员时只淡化帆布。船坞改为双栈桥湿船坞、船台与吊架。模型共享同一份 GLB，选中状态不另读资源。

V5、V7、V8 共用维修派遣、接舷夺船、任务占用和船队集结模块。实际工作的炮位决定当前火力；不把未购买的船计入护航。购买对象仍是舰船，安装直接使用船舱装备。先停止维修接收船，再发布登船命令，避免新命令被停止操作取消。自动火力会保留正在被己方船员接舷的空船，玩家明确下达的攻击仍执行。

无地形网格的演示场景也复用有朝向的水面航路，删除会在接触前卡住的直接转向分支。V7、V8 更积极扩张并为矿区布置防御；经济仍保留殖民主基地和紧急防守的预算。

新增六人「蓝宝群岛」和八人「八方河湾」：前者有主岛、卫星岛和中央大陆；后者有三条浅滩通路、河道和三级矿区。地表覆盖与装饰是确定性的视觉数据，不改变地面通行代价。旧地图的地形、资源、营地布局保持原有哈希。

## 验证

- TypeScript、生产客户端和服务端构建通过；260 个测试文件、2,061 项测试通过。
- 三个版本均完成真实跨海殖民、三门炮安装、跨甲板维修和空船夺取；额外验证明确攻击指令不受自动接舷保护影响。
- 两张新图各运行 900 秒，使用正式命令帧与 AI 运行时，轮换 V5、V7、V8。八人局出现 23 座主基地、265 个单位；六人局发生海上战斗与跨海扩张。
- 在当前 CPU 环境，两个对局的模拟步 p95 约 12 ms；仍有约 120 ms 的个别尖峰。这是模拟耗时，不是渲染帧率。
- 浏览器检查涵盖装备交互与多尺寸布局。云浏览器关闭 WebGL，GPU 视觉与帧率仍需有 WebGL 的设备验收；实际 GLB 几何、遮挡、投影与帆透明通过 CPU 集成测试。
