# 技能图标与选中单位状态栏

选中信息现在用紧凑图标显示当前焦点单位的实际状态。正面状态为绿边，负面状态为红边，召唤时限使用中性色；图标下方只显示剩余时间，作用、数值和来源规则放在悬停详情中。多个单位一起选中时，Tab 切换焦点会切换状态，不合并整组单位的增益、减益。

## 依据与取舍

- [Riot《League of Legends Patch 26.14 Notes》](https://www.leagueoflegends.com/en-ph/news/game-updates/league-of-legends-patch-26-14-notes/) 的 Buff Bar 调整减少已由其他位置清晰表达的冗余信息。这里借鉴其降低重复信息的方向，但不照搬极短状态的隐藏规则：本引擎最后一个有效 tick 的控制状态仍显示 `0.1s`。
- [Valve《Dota 2 7.00 HUD》](https://www.dota2.com/700/hud) 将查询其他单位的信息与玩家控制信息区分，减少 HUD 占用。这里据此采用单个焦点单位的状态区；图标尺寸、颜色和时间格式是本项目的设计选择。

这些资料是呈现参考，不是战斗数值依据。此次没有修改技能、攻击、冷却、伤害或持续时间。

## 实际覆盖

| 状态 | 图标和信息 |
| --- | --- |
| 诅咒、灰烬诅咒 | 区分技能图标，读取实际伤害倍率与剩余时间。 |
| 守护、无敌 | 显示实际免伤状态；有时限时显示倒计时。 |
| 灼烧印记 | 显示易伤标记，详情明确印记本身不持续扣血。 |
| 减速、眩晕、定身、中毒 | 独立图形，显示实际持续时间及控制/毒性伤害作用；包括野怪攻击产生的状态。 |
| 嗜血、战斗号令 | 同属临时攻速层，只显示实际最强者；强效果先结束时，仍有效的弱效果恢复显示。 |
| 心灵之火 | 按实际伤害筛选层显示最强临时防护，不虚构叠层。 |
| 三星光环 | 按同盟、范围、目标类别、存活与舱内规则计算实际来源，取各修正项最强者；`∞` 表示依赖来源的持续光环，不表示永久生效。 |
| 召唤时限 | 用快照 tick 与单位到期 tick 计算，独立于召唤动画。 |

技能冷却仍在命令卡中，永久学会的技能仍在其技能卡中，不重复伪装成临时状态。引擎当前没有通用状态叠层数，因此没有加入假的层数角标。

普通法术、三星主动技能、三星学习候选和被动技能卡使用同一套图形资源，替代技能 emoji。25 个去重技能及 4 个状态图标共 29 张 128×128 WebP；图标路径由公共路径 helper 处理部署前缀。状态条保留键控 DOM 节点，时间变化只更新需要变化的文字；技能卡只在技能改变时替换图像。HUD 每个快照只计算当前焦点，不逐单位扫描全场；战场标识与 HUD 复用相同的有效状态层筛选。

## 验证

定向回归 **4 文件、30 项通过**：状态呈现 8 项、选择控制 11 项、HUD 模型 7 项、资源图标 4 项。状态测试使用实际施法、野怪命中、仿真时间推进与光环计算，覆盖到期、冷却独立、最强防护恢复、攻速不叠加、同盟/入舱/死亡边界、医疗光环目标过滤和召唤寿命。只读呈现前后 checksum 不变。`tsc --noEmit` 与 `git diff --check` 通过。

真实应用入口的 Chromium 验收在 **3D 和 2D 各 8 项，共 16 项通过，页面/控制台错误为 0**。使用真实菜单、地图、选择输入、Tab 与命令按钮；保留原渲染器和命中检测，2D 通过不可用 WebGL2 触发原回退。战斗号令由玩家实际按钮施放；减速和中毒由真实仿真攻击入口生成，随后移除攻击者避免刷新。未直接拼接状态 DOM 或替换状态渲染。额外通过原生选择祭司与打开三星学习面板，验证可见普通法术和三个学习候选的图像都完成加载，图标区域无残留 emoji。
