# 战役与美术资源方向（设计提案，2026-10-04）

## 已确认的现状

`shared/catalog` 是基础规则；`client/art` 和 content painters 是表现层。旧灰烬边境的 cast 将规则变体、英雄成长和专属 painter 打包。专属 UnitModel 没有 pose 参数，旧角色会绕开现在的动作绘制。原首页还直接依赖战役 scenery；本次已把通用装饰抽到 `client/art/scenery.ts`，战役只保留专属 heartwood，首页不再导入灰烬边境。

`story/` 已有 Director、章节、目标、选择、存档检查点和输入回放，值得保留。现有灰烬边境主要接入录制和自动驾驶；正式玩家战役入口、存档界面和完整战役 HUD 尚未接上。玩家模式必须明确 `pilot:false`。不能把录制脚本直接当成玩家战役。

## 建议的数据链路

1. core：基础兵种规则、骨架/动作、材质、通用树石、矿山、商店、碰撞与阴影约定。
2. faction：阵营服装、武器、建筑套件，遭遇战和战役共同引用。
3. campaign：命名英雄、独有物件、地图、章节与对白，只引用或扩展前两层，不偷偷改动对战平衡。
4. chapter / menu scene：明确资产清单与场景配置。首页仅加载自己的场景依赖，运行真实 sim；不直接借用一整套战役脚本。

资产采用稳定命名空间，例如 core/building/shop、campaign/return/hero/captain；缓存键包含资源版本。定义中明确视觉锚点、尺寸、投影、阴影、碰撞占地与是否阻挡。视觉装饰不默认有碰撞；需要阻挡的塔、墙、巨石必须进入实体/障碍系统，不能只画出来。

单位资源包含 idle/walk/attack/hit/death/corpse、武器握点、头像构图；英雄复用骨架和装备配置，避免复制一份过时的人物绘制函数。头像和地图模型共享身份与材质，但构图独立：人形胸像、骑兵保留坐骑、兽类按轮廓取景。

预加载放在客户端资源加载器，不能把异步 Promise 塞进确定性的剧情模拟。选章节后加载代码、地图/碰撞、音频与字体，预热首屏姿势和头像，再开放开始按钮；后台预取下一章。当前多为程序绘制，预加载还包括首次栅格化，不只是下载图片。不能一口气烘焙所有兵种/动作/缩放：现有图集缓存有预算，需要按章释放专属资源。存档记录 campaignVersion，避免新版剧本误读旧的输入回放。

## 四个可迁移的经典故事

以下关卡划分是改编提案，不是原著章节的逐字对应。

### 《水浒传》三打祝家庄：关卡设计最强

一个有限地域，有迷路、情报、救人、联盟、内应和围攻，适合 4 关短篇战役：探路脱困 → 截援救人 → 内应与拆盟 → 内外合围。第一关让玩家用侦察找安全路、控制路口和撤离伤兵，不靠长对白触发下一段。村民、庄兵、中立商店都有任务角色。

资料：
- 原著第 50 回（三打祝家庄）：https://zh.wikisource.org/wiki/水滸傳_(120回本)/第050回
- 第 47 回（二打祝家庄）：https://ctext.org/wiki.pl?chapter=384966&if=gb&remap=gb
- 大都会馆藏《水浒传》木刻本，约 1610–1640，馆藏图标注 Public Domain：https://www.metmuseum.org/art/collection/search/712497
- 东京富士美术馆，歌川国芳鲁智深版画，可研究姿态与武器构图；这是日本再创作，不能当宋代服饰实证：https://www.fujibi.or.jp/en/collection/artwork/09863/

代价：需要一套中国寨堡与衣甲，复用动作系统而非套上现有西式模型。个人最想尝试这一条。

### 色诺芬《万人远征记》：长线战役最自然

雇佣军失去指挥核心、被困异乡，组织撤退直到见海。核心是保住一路带下来的队伍。可设计收拢残军、渡河、夜间取粮、山口阻击、雪地撤离、港口登船。保留营地建设和资源决策，但用有限补给代替每关从零刷完整科技树。

资料：
- 全文及下载：https://www.gutenberg.org/ebooks/1170
- Perseus 第三卷，指挥官遇害后的困局与军队重组：https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Aabo%3Atlg%2C0032%2C006%3A3
- 大都会希腊头盔与护胫（馆藏开放图）：https://www.metmuseum.org/art/collection/search/703054

代价：直接还原古希腊需要新装备；若只移植故事结构到现有幻想世界，必须明确属于改编，不伪装历史还原。

### 柯南道尔《白色军团》：现有资产利用率最高

百年战争背景的历史冒险小说，适合围绕一支佣兵队设计护送、围城、突围和契约抉择。现有骑士、弓手、城堡、商店和营地可以直接服务它。最适合作为“先做一关能玩的高完成度样板”的路线。

资料：
- 原著全文：https://www.gutenberg.org/ebooks/903
- 《弗鲁瓦萨编年史》手抄本彩饰临摹集，包含围城、城堡、舰队、军阵、旗帜等图版：https://www.gutenberg.org/cache/epub/65908/pg65908-images.html
- 另一册：https://www.gutenberg.org/ebooks/64454
- 大都会布面甲实物：https://www.metmuseum.org/art/collection/search/23080

提案不是直接照抄小说所有事件；挑选能转化为地形、部队和目标变化的段落。

### 《尼伯龙根之歌》：最适合冷峻幻想气质

英雄、盟誓、背叛和复仇可以支撑低饱和、铁灰与暗红的世界，以及少量真正有分量的神话生物。尸体、战后废墟可成为持续叙事资源。

资料：
- Needler 译本：https://www.gutenberg.org/ebooks/7321
- 全文：https://www.gutenberg.org/cache/epub/7321/pg7321-images.html
- 海德堡数字化圣加仑手稿：https://digi.ub.uni-heidelberg.de/diglit/stibsg_cod857/0249

难点：后半部大量宫廷/厅堂悲剧并非天然 RTS 关卡，需要认真取舍；不要不加区分地混入瓦格纳《指环》的人物与情节。

## 第一阶段交付边界

先选一个故事做 10–15 分钟完整关卡：正式入口、资源加载、目标、可控角色、胜败与重试、存档读取、真实碰撞和战斗。验证金矿/商店/营地与主建筑共享光照和交互规则。旧战役留作引擎回归样例，不把其全部对白和模型原样迁入新作品。

美术统一规则：暖而克制的主光、冷灰阴影；大面积木石布料哑光，金属与切边窄高光；队色只放在少数布片与徽记；接地阴影紧贴地面；UI 用沉静的炭灰与少量旧金，不让每个头像各有彩底和装饰圈。真正的统一来自这些约束贯穿资源库，而非全屏泛光。
