# 瞄准与两族阵容

远程武器增加首次瞄准成本，站定连续射击保持原有冷却节奏。骑射手保留风筝定位，用更高的机动性和更大的位移容错换取较低的攻价比。

## 瞄准规则

- 普攻冷却结束且目标进入射程后，准星按固定速度追踪目标当前的位置；到位才射击，射击后开始武器冷却。
- 准星只记位置，不绑定目标身份。每次推进时比较从准星与射手出发的距离，使用较短的路径；切换目标也能复用准星。
- 位移容错围绕上一次射击的站位计算。每次成功射击更新站位锚点；移动指令、冷却经过和切换目标均不会刷新锚点。
- 小幅实际位移保留准星，累计位移超过容错就失效。正常移动、碰撞挤位、击退都走同一规则；登船时清除准星。
- 所有远程单位均可使用 **预备瞄准（J）**，站定瞄准一个地面点，无需敌方目标，也可在冷却中准备。敌人进入武器射程后自动开火，不追出阵地。
- 准星和瞄准线只对该单位的所属玩家显示。盟友、敌人和无所属玩家的观战画面均不显示；预备瞄准不会增加视野。
- 远程武器技能同样需要瞄准；近战、冲车撞击、防御塔与治疗、诅咒、召唤等法术不增加这项成本。

## 初始参数

这些是供实战观察的初值，集中在共享兵种规则和瞄准模块中。

| 项目 | 数值 |
| --- | --- |
| 普通远程位移容错 | 6 世界单位 |
| 骑射手位移容错 | 72 世界单位 |
| 准星移动速度 | 按武器分别设定，单位为世界单位 / 秒；全局系数 2/3 |
| 模拟频率 | 20 tick / 秒 |

例如普通弓手满射程首次瞄准约 1 秒；静止目标的下一发无需重复这段启动时间。骑射手可以在两发之间明显换位，普通弓手走出小范围后需要重新启动瞄准。

## 阵容分工

| 位置 | 林地族 | 灰烬族 |
| --- | --- | --- |
| 顶线步兵 | 步兵、长枪兵 | 劫掠者、奔袭者、灰烬守卫 |
| 马厩 | 掠袭者、骑士、骑射手 | — |
| 工坊 | 床弩、魔像 | 铁甲冲车、投石机、连弩炮车 |

灰烬守卫沿用原林地守卫的战斗数值，改由灰烬熔炉训练并使用灰烬外观。工程武器的种族归属同时约束 UI、训练校验和 AI 选择。

骑射手为进阶单位：109 生命、90 世界单位/秒移速、10 攻击、264 射程、1.5 秒攻击冷却、150 金、2 人口。较普通弓手更快、更贵、输出更低，定位是持续骚扰和风筝。

## AI 与画面

V5 会按射击窗口决定是否换位，骑射手优先利用较大的瞄准容错；有真实近战掩护的 V7/V8 法师会先完成安全的近距离射击。失去掩护、被贴身或进入塔射程时仍会重新站位。攻击移动会重新检查在途箭矢，避免等待瞄准期间反复打已经判定击杀的目标。

首页海上船队的船体不再套用行走晃动姿态，航行仍使用原来的模拟路径。

## 验证

回归覆盖首次射击、连续输出、目标运动、切换目标、射击锚点、小幅与累计位移、骑射风筝、预备瞄准、武器技能、所属玩家 UI 和保存后继续模拟。自然对局检查正常运行、支援、撤离和登陆行为，不以排行榜成绩为优化目标。
