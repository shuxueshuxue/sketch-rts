# 潮汐王座

线上入口：主菜单 → 战役 · 潮汐王座 → 开始远征。

远征队与基地由玩家控制；海军议会和王廷各有主力、预备队、工程兵与舰队。占领港口产生补给，补给支付增援和舰船。侧翼控制稳固时主力会支援其他受威胁港口。外海岛屿通过舰船抵达、运输卸载、驻军与占领规则争夺，不在指定时刻强制换旗。

目标依次为控制三港、摧毁王廷堡垒、连续守住三港一分钟；统帅或远征司令部毁灭即失败。统帅不是应该直接投入密集敌阵的无敌单位：使用遗物支援主力，带攻城部队前进，传送后固守。

## 操作

- 点击「统帅」「司令部」「王廷堡垒」或港口名称定位；「远征军」选择自己的非海军战斗单位。
- 右键移动/攻击，A 攻击移动，H 固守；Ctrl + 数字编队。
- 点击遗物，再点击地图；圆圈显示范围，红色表示超射程。右键或 Escape 取消。
- 「舰队、攻城与工程」提供生产队列和工程计划；队列按钮的 × 取消并退款。
- 工事先下达计划，工程兵走到现场后才扣费并生成可被攻击的施工实体。
- 暂停时可下达指令；1/2/4 倍速只改变真实时间调度，不改变逻辑步长。重伤/基地告急会战术暂停，点击继续恢复。
- 每分钟自动存档，可手动保存；读档先暂停，失败不会覆盖最近的自动存档。

## 资源与规则分层

- `src/shared` 保存遭遇战共用的命令、碰撞、地形导航、伤害、建筑和单位基础规则。
- `src/campaigns/tidebound/campaign.ts` 只包含确定性的战役状态、地图、命名变体、胜负条件与战略调度。时间来自逻辑帧，存档包含完整变体和工程/补给状态。
- `src/campaigns/tidebound/art.ts` 将战役变体 ID 映射到独立手绘模型，保留基础兵种规则。新增舰船和攻城器械不会替换其他战役同类单位的图像。
- `src/client/art/building-models.ts` 提供共用正交投影构造、材质和光向，工事/王廷堡垒通过独立模型标识绑定。
- `src/client/tidebound-worker.ts` 负责浏览器调度、战术暂停和消息传递；机器时钟不会进入确定性战役脚本。
- 菜单背景仍使用独立场景实例，不复用正在游玩的战役状态。单位、建筑共用基础画笔；场景自定义模型保留命名边界。

## 当前边界

这是首个可完成的群岛战役版本。全图 5000 余实体已实装，但完整浏览器性能仍取决于电脑和可见单位密度；目前单场逻辑只在一个 Worker 内运行。兵器各有数值/功能差异，尚未完成大样本平衡定标，不能视为已经证明的帕累托最优配置。测试记录见 `reviews/tidebound-iterations.zh.md`。
