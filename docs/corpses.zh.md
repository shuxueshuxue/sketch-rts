# 持久素描尸体

47 种单位均有倒地/残骸画法。灰褐色块、折断轮廓和斜向排线，保留兵器、衣袍、坐骑、角翼等辨识特征。石像留下碎块，船只留下残骸，灵体留下淡痕。相近单位共用身体结构和装备画法，不是 47 套独立绘画。

真实死亡时在 `GameSnapshot.corpses` 保存独立记录：尸体 ID、原单位 ID、种类、归属、位置、半径、死亡 tick、自定义 variant。与瞬时特效分离，参与快照、恢复和确定性校验。最初透明度 0.58，8 秒内逐渐降至 0.40 并保持，**没有超时或数量上限删除**。镜头外只跳过绘制，记录仍在。

尸体不占人口、不挡路，不进入普通索敌或选中列表。上船、脚本离场、召唤自然到期不生成尸体；船只死亡时以船骸代表，不在水上散落乘客人体。实际尸体技能、复活、资源消耗和腐化阶段本轮未实现，未来可基于记录定义规则。自定义剧情角色保留 variant 信息，现阶段按基础单位画残骸。

绘制与活着单位共享有界 atlas，先画在地面上，再画建筑和活着的单位。不随受击或攻击动画跳动。

确定性校验版本更新为 3。普通旧存档没有尸体字段也能恢复；剧情版本 2 的存档仍按旧规则校验并恢复，新保存使用版本 3；更早的版本 1 保持原来的拒绝行为。

复现：

```sh
node --import tsx scripts/render-corpse-review.ts
node --import tsx scripts/record-corpse-review.ts
```

图片与真实战斗录像位于 `art/corpses/`。验证覆盖真实死亡只生成一次、长期保留、非死亡离场不生成、船舱乘客处理、快照拷贝与恢复、旧存档兼容、校验参与、全部单位 atlas 边界；另跑客户端、录像与确定性相关回归。
