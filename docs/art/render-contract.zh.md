# 世界物体渲染契约

适用范围：对局和首页场景里，地图上的每一个东西，包括单位、船、建筑、商店、营地、金矿、石头和门、树、草和花、路边物件、王城街道的道具、地上的物品、尸体。
配套文件：作画规范（docs/art/prop-painting.zh.md，Art Lane 负责）。作画规范规定"脚点在素材画布的哪里"，本契约规定"引擎怎么用脚点"。

## 为什么要有这份契约

两个问题是在真实浏览器里看到的（截图见 docs/validation/render-contract/）。

- **遮挡错误。** 树、石头、门、金矿、物品、尸体和所有场景道具（王城的房子、酒馆、摊位、路灯、树、推车等）都画在 3D 层下面的 2D 地面画布上，因此任何单位、建筑和船都压在它们上面，不管谁在前谁在后。例子：bareDuel 里一个步兵站在树林北边（脚点 y=4570），它前面那排树的脚点在 y≈4592，树冠本应挡住它的腿，实际却是步兵画在树冠上。纯 2D 回退路径也一样，道具在单位之前单独画一遍，不参与按深度排序。
- **阴影方向不一致。** 3D 太阳在屏幕上把阴影投向右上方，约 29°（world-layer.ts:319，光线方向是 (+450, −650, −250)）。素材自己画的阴影都朝右下或正下，例如树、道具、建筑剪影、金矿、石头。在 3D 模式下这两种阴影同时出现：王城里行人的影子朝右上，路灯、摊位、桌子只有脚下的椭圆，井的影子是一块右侧的暗方块。

另外，两条路径的锚点也不一致：同一个单位，2D 路径把脚画在 y+17×缩放，3D 路径画在 y；建筑在 2D 里的地面中心要往下挪 0.63r。

## 规则

### 1. 每个物体声明两个量

- **脚点**：物体接触地面的那一点的世界坐标。单位是双脚，建筑和房子是地基正面的中点，树是树干根部，船是吃水线上船体的中心。
- **高度**：物体立起来有多高，用世界单位表示。阴影的长短按它算，被点选的范围也按它算。

另外分两类：

- **立体物件**：会挡住别的东西、会投下阴影。包括单位、船、建筑、商店、营地、金矿、树、石头、门、房子、摊位、路灯、推车、桶、木箱等。
- **地面印记**：贴在地上，不挡任何东西，也不投阴影。包括地形和路、铺石路面、排水沟盖、地上的花草纹理、血迹和焦痕、地上的物品、尸体。

每个道具种类在登记时必须二选一，不能不写。

### 2. 画在脚点上

素材画布里的脚点由作画规范规定。引擎把它放到世界脚点上，2D 路径和 3D 路径都一样，缩放只围绕脚点进行。不允许为了排序挪图，比如 paving() 里 translate(0, 39) 那种做法。

### 3. 遮挡只看脚点深度

- 所有立体物件在**同一个按深度排序的过程里**绘制，没有"先画道具、再画单位"这样的固定先后。
- 深度就是脚点的世界 y 坐标（相机朝北倾斜，世界 y 越大越靠近观众）。y 相同时依次比 x 和 id，保证每帧顺序稳定。
- 3D 路径用深度缓冲，立体物件都做成直立的卡片或模型，底边落在脚点上。2D 路径按上面的键排序后一次画完。
- 地面印记永远在所有立体物件下面。

### 4. 阴影由引擎统一生成

- 全图只有一个光照方向，就是太阳。素材**不画投影**，也不画脚下的阴影椭圆。素材里的明暗只用来表现受光面，受光方向和太阳一致（见作画规范）。
- 投影的方向和长度只由光照方向和物体高度决定。3D 路径用太阳的阴影贴图，2D 路径把物体的剪影按同一个偏移量压扁画在地上，偏移量 = 高度 × 光照系数。
- 地面印记不投阴影。

### 5. 首页和对局用同一套规则

首页场景（presentation: true）和对局走同一条绘制路径，没有场景专用的排序或阴影规则。场景只能新增道具种类，新种类同样要按第 1 条登记。

## 待定：光照方向（需要确认）

现在 3D 太阳从左下方照过来，阴影投向右上；而所有手画素材，包括正在用的建筑、树、道具的受光面和自带阴影，都是按左上方来光、阴影投向右下画的。

建议把太阳改成从左上方来光（世界里的西北方、相机背后偏左），让投影落向右下。这样现有素材的受光面不用重画，和作画规范也一致。这是美术取向上的选择，需要确认后再改。

## 测试

在一张地图上随机摆放立体物件和单位，检查两件事：

- 绘制顺序只由脚点深度决定；
- 两个物体的画面重叠时，深度大的那个盖在上面。

2D 路径和 3D 路径各测一次。另外保留几组真实浏览器的前后截图：树林边的步兵、王城街道。
