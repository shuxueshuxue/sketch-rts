# 装饰物作画规范

适用范围：游戏里和首页场景里，所有手画的世界物体素材。包括树、石头、草花、路边物件，王城街道上的房子、酒馆、摊位、桌凳、路灯、桶、箱子，以及以后新增的道具。建筑和单位另有自己的模型和卡片，但比例和光照也按本规范来。

配套文件：[渲染契约](render-contract.zh.md)（UX Fix Lane 负责）。本规范规定"素材画布里的脚点在哪、素材怎么受光"；渲染契约规定"引擎怎么用脚点排序、怎么生成阴影"。两份冲突时，以渲染契约为准，同时修改本规范。

方向：A"墨线战图"（docs/art-direction.zh.md），即墨线、三档受光、纸面配色。王城借鉴英雄无敌 3 城镇的几条原则（见 capital-reference.zh.md），只借原则，不借素材。

## 1. 画布和脚点

- **画布原点 (0, 0) 就是脚点**，也就是物体接触地面的那一点。每种物体的脚点：
  - 房子、酒馆这类建筑：地基正面那条边的中点。
  - 摊位、桌子、长凳：前排两条腿连线的中点。
  - 路灯、旗杆：杆子落地的中心。
  - 桶、箱子、袋子这样的一堆东西：这一堆的地面中心。
  - 树：树干根部的中心。
- 画布 y 轴向下为正。立体物件的所有笔画都在 y ≤ 0，接地暗边也画在这个范围以内（见第 3 节）。不允许为了让排序"看起来对"把整个画面平移，比如 paving() 里那种 translate(0, 39)。
- 每个素材登记两个数：
  - **高度**：画面最高点到脚点的距离，用世界单位表示。渲染契约用它算阴影长短和点选范围。
  - **类别**：立体物件，或地面印记（见第 7 节）。
- 缩放只围绕原点进行，所以同一个素材放大缩小以后，脚点不动。

## 2. 比例

以一个人的高度为尺子：H = 45 世界单位。这是实测值：footman、worker、archer 的卡片从脚到头顶画了约 57 个绘制单位（y 从 +15 到 −42），3D 卡片再按 0.8 缩放（world-renderer 里的 `models ? .8`）。地图格子是 32 世界单位。

| 物体 | 高度 | 占地 |
|---|---|---|
| 平民、士兵 | 1 H | 约 0.5 格 |
| 桶、木箱、粮袋 | 0.35–0.5 H | 一个约 0.4 格 |
| 长凳、桌子 | 0.5–0.6 H | 1–1.5 格 |
| 摊位（带棚） | 1.3–1.5 H | 2 格宽 |
| 路灯 | 1.6–1.8 H | 一个点 |
| 两层民房（到屋脊） | 2.6–3 H | 3–4 格宽 |
| 酒馆 | 3–3.4 H | 4 格宽 |
| 游戏建筑（兵营、塔、市政厅） | 按自己的占地缩放，见 world-layer 的 @@@building-rise | 按自己的占地 |

规则：街边道具不能比民房高，民房不能比城里最矮的游戏建筑高。王城里的市政厅和塔要始终是最高的轮廓，场景的重心要清楚。

## 3. 受光（和渲染契约的太阳方向一致）

- **光从屏幕左上方来，略靠观察者一侧**：朝向观众的正面受光，东侧（右侧）暗；投影由引擎生成，落向右方、略偏上（渲染契约里的太阳，world-layer 的光源方向）。游戏建筑的 3D 卡通着色、2D 建筑画法（building-models.ts 里 paintBuildingModel 的受光项）和单位卡片都是这一个方向。素材从前画的“脚下椭圆落向右下”是 2D 时代的习惯，和这个太阳不一致，所以去掉。
- 每个面只有三档明度，对应 3D 那边的三档卡通着色：
  - **亮面**：顶面，以及朝左、朝上的面。用本色，或者略提亮（×1.05）。
  - **中间面**：朝向观众的正面。本色 ×0.9。
  - **暗面**：朝右的侧面，以及挑檐下面。本色 ×0.72，略偏冷，向 #56686b 靠一点。
- **不画投影，也不画脚下的阴影椭圆**，这两样由引擎生成。允许的只有接地处 1–2 单位宽的一道暗边，作用是"接触"，不是"影子"，只画在物体自己的轮廓里面。
- 高光只出现在金属、石材切边和玻璃上，是一笔窄线，不铺大面积。

## 4. 线

- **外轮廓**：墨色 #293c35（kit.ts 里的 INK）。在缩放 1 下线宽 1.0，和 3D 建筑 1.5 屏幕像素的墨线在默认缩放下一样粗。
- **内部结构线**（木构件、窗框、门框）：本色加深 30% 左右，线宽 0.6–0.8，不用墨色。
- **材质纹理**（瓦片、砖缝、木纹）：本色加深 15–25%，线宽 0.4–0.55，只画两三行示意，不逐块画满。
- 不用纯黑，也不用超过 1.4 的粗线。现在王城房子外轮廓的 1.1–2.6 粗线和墨色木构件（TIMBER 2.0–2.6）都要改。

## 5. 配色

和游戏建筑用同一套材质色（building-models.ts）：

| 材质 | 本色 | 用途 |
|---|---|---|
| 石材 STONE | #dfd3b7 | 墙体、台阶 |
| 切石 CUT | #b8b5a0 | 墙基、柱础、铺面压边 |
| 木 WOOD | #8b7054 | 木构件、桶、桌凳 |
| 石板 SLATE | #71928f | 屋顶（冷） |
| 铁 IRON | #86948f | 灯架、箍、锁具 |
| 玄武 BASALT | #898b7c | 重石、路缘 |
| 铜 COPPER | #b3825d | 暖色屋顶、招牌 |
| 黄铜 BRASS | #d2b779 | 灯、装饰 |

- 墙面、屋顶这种大面积，饱和度不超过 HSL 35%。只有布篷、花、旗帜、货物这些点缀色可以到 55%，而且一个物件里点缀色不能超过画面的 15%。
- 灯火和窗光用 #e0bf74 一个暖黄，夜景以外不画光晕。
- 队色只用在旗帜、徽章上。王城是中立的城，道具不带队色。

## 6. 细节密度

- 在缩放 1 下，每 32×32 世界单位里，内部笔画（结构线加纹理线）不超过 12 笔。
- 大面积墙面要留出平涂，只用一次材质纹示意。英雄无敌 3 的城镇建筑也是这样，墙面大块平涂，细节集中在门窗、檐口和屋顶的边上。
- 细节要集中：门、窗、招牌、檐口占一个物件画面细节的大约 70%。
- 人物卡片在默认缩放下大约 40 像素高。比人物小的物件（桶、箱子、灯头）最多三四个色块加两三笔线，在 40 像素尺度下要能一眼认出来。

## 7. 立体物件和地面印记

| 类别 | 王城的素材 |
|---|---|
| 立体物件（参与深度排序，引擎投影） | 房子、酒馆、摊位、桌子、长凳、路灯、花坛、桶、木箱、粮袋、树、推车、旗、井 |
| 地面印记（永远在下面，不投影） | 铺石路面、排水沟盖，以及地上的花草纹、落叶这类 |

地面印记的画布原点是印记的中心，没有高度，必须和地形一样平。不画侧面，也不画立起来的边。

## 8. 验收

每张新画或重画的素材，在合并前都要过这几条：

1. 原点是脚点，立体物件的所有笔画都在 y ≤ 0 范围内；登记了高度和类别。
2. 画面里没有投影，也没有脚下的椭圆。
3. 受光：顶面和左侧面亮，右侧面暗。
4. 外轮廓用墨色，线宽 1.0；内线和纹理按第 4 节。
5. 用的是第 5 节的材质色；点缀色占比和饱和度不超标。
6. 比例：和一个人物、一座游戏建筑放在同一张截图里对比，符合第 2 节。
7. 截图：和人物、建筑同框的前后对比图（真实浏览器，3D 和 2D 两条路径各一张）。
