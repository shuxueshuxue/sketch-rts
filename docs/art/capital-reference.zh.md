# 王城参考板：从英雄无敌 3 借什么

owner 的要求：王城要做得精致，建筑要好好画，可以带一点英雄无敌 3 的风格。约定照旧：**只借原则，仓库里不放任何 HoMM3 素材**，截图、贴图、拼图都不放。参考只用外部链接：

- HoMM3 城镇介绍（社区维基）：https://heroes.thelazy.net/index.php/Castle
- 开源重写 VCMI（规则和资源格式是公开的）：https://vcmi.eu/

本文说明借哪几条原则、怎么落到方向 A"墨线战图"里，以及怎么和[渲染契约](render-contract.zh.md)、[作画规范](prop-painting.zh.md)接上。

## 现在的问题（main 上的截图：docs/art/capital/before.webp）

- 房子是平涂的剪贴画：每个面一种颜色，外轮廓是 1.1–2.6 粗的墨线，木构件也用墨色粗线。游戏里的建筑是三档卡通光加 1.5 像素的细墨线，两边看起来像两个游戏。
- 路面是灰砖平铺，一块一块都画出来了，整条街最显眼的反而是路面。
- 树是几何三角形叠出来的，旁边的房子又是另一种手绘画法，两种画法放在一起。
- 阴影的方向各不相同：素材自己画的椭圆朝下，3D 太阳的阴影朝右上。渲染契约会统一处理。

## 借的五条原则

1. **轮廓先行，屋顶是主角。** HoMM3 的城镇建筑先用屋顶和塔楼的剪影说清楚"这是什么"。屋顶高、坡陡、出檐深，占建筑画面的一半左右，墙面反而简单。
   落到我们这里：民房的屋顶高度占整体的 45–55%，酒馆和市政厅的屋顶有错层和山墙，塔有尖顶。墙面按作画规范第 6 节留平涂。

2. **材质分层：石基、木构、灰泥、瓦，层次分明。** 底层是一圈深色的石基，中间是浅色的灰泥墙加木构架，上面是有颜色的瓦顶。每一层的明度差拉开，一眼就分得出来。
   落到我们这里：只用作画规范第 5 节的材质色，墙基用 CUT 或 BASALT，墙用 STONE，木构用 WOOD，屋顶用 SLATE（冷）或 COPPER（暖）两种。一条街上冷暖屋顶交替，不再每家一个颜色。

3. **统一的左上光，亮面和暗面分得开。** HoMM3 的城镇画面是一个方向的光：屋顶朝光那面亮，侧墙暗，挑檐下面一道深影。
   落到我们这里：和渲染契约的太阳一样，从左上方、略靠观察者一侧来光，正面受光、东侧暗，用三档明度（作画规范第 3 节）。投影由引擎生成，落向右方、略偏上；素材里不画。

4. **细节集中在门窗和檐口，大面留白。** 精致感来自门、窗、招牌、檐口线脚、烟囱这些"点"，不是来自满墙的砖缝。
   落到我们这里：每栋房子有一个视觉焦点（门、招牌或挑出的窗）。砖缝和瓦纹只画两三行示意。

5. **主次分明的天际线。** 城堡、市政厅、塔最高，民房围着它们，街道道具最矮。
   落到我们这里：按作画规范第 2 节的比例。王城的市政厅（citadel 模型）和塔是整幕的最高点，民房不超过 3 H。

**不借的**：HoMM3 的高饱和度和厚重的油画质感。我们是纸面墨线，大面积的饱和度上限是 35%（作画规范第 5 节）。

## 王城里哪些东西和游戏共用

| 王城里的东西 | 用的什么 | 改它会不会影响游戏 |
|---|---|---|
| 市政厅 | 场景专用的 citadel 3D 模型（buildingModels 覆盖） | 不会 |
| 防御塔、兵营 | 游戏的 defenseTower、barracks 3D 模型 | **会**：改模型就是改游戏里的这两种建筑 |
| 井 | 场景道具里的 well，3D 模型 | 不会（游戏里没有） |
| 民房、酒馆、摊位、桌凳、路灯、花坛、桶箱 | 场景专用的 2D 素材（menu-capital-street.ts） | 不会 |
| 树、推车、旗 | 共用的 2D 素材（art/scenery.ts 的 CORE_SCENERY） | **会**：树和推车在游戏地图上也用 |

所以打算这样做：

- 民房、酒馆、摊位这些场景专用的建筑，可以随便重画。
- 防御塔和兵营不在王城里单独改。如果要改，就作为游戏建筑统一改，另走 PR，并附游戏内的前后对比图。
- 树走渲染契约那边的地形卡片统一方案，不在王城里单独处理。

## 效果图怎么出

两版，都用真实引擎渲染，不画概念图：

- **A 版：3D 同语言。** 民房、酒馆、摊位用和游戏建筑完全一样的流程来建：building-models.ts 的几何体，Blender 导出 glb，三档卡通光，1.5 像素墨线。这样和游戏建筑是同一种语言，引擎直接给出阴影和遮挡。
- **B 版：2D 精修。** 素材仍然是 2D，按作画规范重画，包括细线、三档明度、材质色、去掉自带的阴影。

两版都放在同一个机位，和 main 并排截图，交给 owner 选。我倾向 A：王城和游戏建筑一个画法，以后加房子也只是加几何体。
