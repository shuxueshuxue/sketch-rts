# 撤销人形骨架方案的视觉验收结论

用户再次明确否定 5d7ebe0 的姿态。此前测试通过、全资产覆盖、握点连接正确，以及上一轮所谓“修正”，均不构成美术验收通过。当前分支人物造型仍未获认可，不应以工程指标将此问题关闭。

## 实证对照

`npx tsx scripts/art-authored-baseline-review.ts` 从 Git 提取 9819046 的原始人形 painter，在同一 Canvas、颜色、缩放、帧与运行环境绘制 8 个兵种的待机/行走/接触，对照 5d7ebe0。提取的模块只在评审时短暂存在，运行后删除，不引入生产兼容层。原始与当前均是完整人形 painter；本对照不覆盖旧版非人类资产或所有游戏镜头。

人工查看 original-vs-current.png 的结论：

- 原版肩、肘、手由作画直接决定。屏幕投影中的线段长度可变，能压缩手臂；当前固定 11/10.5 的二维骨长错误地把投影长度当作解剖不变量。握点接近肩膀时只能强行屈肘，翻转 IK 分支仅改变折向，不能解决根因。
- 原版普通持械臂先画、躯干后画，允许身体遮挡关节。当前许多主手整条画在身体前面，盔甲轮廓被长折线割开。层次同样是姿态设计，不应固定成通用渲染顺序。
- 原版按角色分别画弓的拉弦臂、骑枪握持及持杖姿势。当前“指向目标”的通用 contact angle 把法师画成平举长杖，动作意图变了。
- 原版攻击幅度为 [1,.65,.15,-.28,-.15,0]，有反向回弹。当前 [1,.76,.48,.24,.08,0] 单调恢复，使不同武器的节奏趋同。不能直接全局恢复旧数组；放箭、施法、砍击应各自处理，且继续服从已发生的模拟事件。

## 新的边界

保留有效的 GPU/缓存/资源生命周期改进。废弃“所有人形必须服从同一二维定长 IK”的约束及其作为视觉正确性的测试标准。姿态由作画决定：独立的肩/肘/手、武器姿态、遮挡顺序、关键帧时间及必要的投影缩短；武器挂点从最终画出的手获取，不能反过来迫使整个人服从统一握点。复用限于画面确实兼容的动作，允许专用姿势与专用绘制。

下一轮应先恢复旧版有效的侧向轮廓与动作节奏，再分别制作上/下方向、施法、待机和换装。先用短片证明典型兵种的效果，再扩大迁移。禁止把此次历史对照当成已经完成的生产恢复；当前生产仍是被否定的 5d7ebe0，尚未实施新的姿态表达。此提交只有诊断、可复现对照和路线修正。
