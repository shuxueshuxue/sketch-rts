# 持械方向改为预备攻击方向

基线 `997a306`。上一版过度压缩了连续攻击的幅度：水平长枪的持械握点几乎等于命中握点；回收动画又被第二次混入持械姿势，削弱行程并抹掉了回弹。本次修改绘制姿态，不修改命中、攻击速度、冷却或模拟逻辑。

## 具体调整

- 长枪把握点沿攻击方向往身体附近收，留出下一次送出和抽回的行程。枪身保持上/平/下攻击平面，避免每击都大幅转回原始闲置姿势。
- 剑、斧和重型近战武器采用收在身前、保留挥动空间的预备姿势。弓与法杖分别保留自己的动作；持械鱼人、食人魔采用对应身体的握点。
- 用预备姿势替换动作的起始/回归位置，保留原动作曲线及负向回弹。取消对已经算好的动作再做一次整体混合，避免把攻击压成轻微抖动。
- 保留此前的 3 秒持械方向记忆、450 ms 超时收回、移动/后退、朝向锁定与血迹挂点；没有新增状态、纹理缓存维度或模拟规则。命中/释放帧不变，不在伤害发生之后追加假起手。

以长枪变体 1 的原画坐标为例，预备握点到接触握点的距离：

| 方向 | 上一版 | 本次 |
| --- | ---: | ---: |
| 上 60° | 7.07 px | 14.21 px |
| 水平 | 1.00 px | 9.00 px |
| 下 60° | 6.71 px | 13.45 px |

这是原画握点行程，不是屏幕距离或命中范围。长枪完整持械状态的回收阶段，枪身与目标平面的偏差小于约 3.5°；力度主要来自位移，不靠重新大幅转枪。
