# 上、平、下方向动作修订

当前分支的生产 painter；12 秒，三列目标方向 -60° / 0° / +60°，三种变体与两种朝向。待机和接触帧有评审停留时间，不是实战录像，不补造命中前蓄力。

撤销“枪尖必须高于屏幕脚底线”的错误约束及其测试。下戳保持完整枪长、自然较低握点；身体随方向略有倾斜，脚部锚点不变。枪尖、投射物出发点共享同一套变换。向上施法的手掌避开面部。

真实约束是贴图完整、握持位置和发射点一致、事件时刻不变。骑兵直向上出枪需要更大的画布，因此活动作域从 160 扩至 176；这是明确的空间成本，不宣称它提升性能。贴图面积上限增加 21%，裁切缓存仍只留实际像素；GPU 分配成本需要后续实测。
