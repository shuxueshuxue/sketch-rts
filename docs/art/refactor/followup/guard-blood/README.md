# 攻击后的持械方向与接触式溅血

本轮在独立分支 `art/composable-rendering` 上继续，比较基线为 `300e606`。只修改表现系统，未改变伤害、命中、AI、经济、模拟随机数或回放事实；未合并、部署。

## 行为

- 攻击收势后保留最后攻击方向 **3 秒**，再用 **450 ms** 收回。站立、行走和后退均适用；再次攻击刷新方向和时间，施法、工作覆盖旧持械状态。计时随模拟推进，暂停和网络停顿不会让动作自行继续。
- 保留的是放松的持械姿势，不是伸直手臂的攻击定格。武器各有绘制姿态，未加入肘部 IK 或枪尖不得低于地面的约束。无武器野兽不额外生成持械姿态缓存。
- 修复跨过实际命中 tick 的快照被冷却推断覆盖的问题。实际释放事件优先，避免丢失方向；接触帧与投射物武器挂点保持一致。
- 原有濒死/致死生物伤害触发条件不变。血滴带初速度、重力与少量回溅；路径与附近身体或实际武器绘制线段相交后留下接触血迹。每次飞溅对每个接收者最多留一个身体与一个武器印记，防止贴近伤口的武器截获所有血滴。
- 身体血迹跟随接收者位置和朝向；武器血迹记录武器身份、线段及沿线位置，随姿势、转动和移动更新。换武器、丢弃或投出后清除旧武器印记。新增附着血迹保留 6 秒，后 3 秒淡出；原有地面血迹仍按原来的 9 秒寿命处理。
- 新增附着印记上限 192；不为每个沾血单位生成纹理变体。WebGL 血墨仍合并为一个实例绘制调用。Canvas、WebGL、剧情模型与减少动态效果设置共用对应的绘制姿态来源。

## 实际画面

先看 **world.mp4**（8 秒、1280×900），再看 **blood-closeup.mp4**（同一录像的裁切放大）。后者没有另造动画或血滴。PNG 分别展示保留方向、移动中保留和最终收回。血迹在正常战场比例下较小，放大视频用来检查附着关系。

使用生产 WebGL 渲染器和真实模拟。四组长枪分别向左/右、上/下攻击并击杀目标，其中两组随后执行真实移动命令后退。附近混战自然产生武器血迹；另一个区域通过剧情接口 `strikeUnit(75, 'melee')` 造成真实伤害，便于稳定观察强打击及旁观者沾血。这是明确设定的验证场景，不冒充随机比赛录制。

`world.json`：站立与行走方向保持、超时收回、旁人沾血、武器沾血全部通过；保留阶段错误朝向 0，WebGL 错误 0，浏览器错误 0。录制 80 帧，每帧推进 2 个模拟 tick；录制专用保留缓冲不影响生产设置。

复现：

```sh
node --import tsx scripts/combat-effects-proof.mjs --timeout-ms 180000 \
  --fixture scripts/art-guard-blood-fixture.ts \
  --out docs/art/refactor/followup/guard-blood/world.json
```

## 开销：新增效果有成本

同一容器、同一静态 1000 单位和每 12 tick 48 条固定命中/释放事实，120 帧预热、360 帧计量。只测动画、朝向、姿态投影与溅血 **CPU 表现处理**；不包含模拟、纹理绘制、GPU 或视频采集，不能解释为游戏帧率或完整渲染时间。

| 指标 | 基线 300e606 | 新增功能后 |
| --- | ---: | ---: |
| 平均 ms | 1.080 | 3.184 |
| p50 ms | 0.882 | 3.024 |
| p95 ms | 2.038 | 4.561 |
| 最大 ms | 3.444 | 9.667 |
| 身体/武器印记峰值 | 48 | 240 |
| Node 全进程堆峰值 bytes | 62,644,496 | 105,192,768 |

均值增加约 2.10 ms，p95 增加约 2.52 ms；**这次新增效果不是性能提升**。全进程堆峰值受加载器、模块图和 GC 时机影响，不是渲染器保留内存；新版各轮强制 GC 后约 20.28–20.36 MB，完整原始值见 JSON。接收者空间索引、每快照形状缓存、标量接触计算和有界印记降低了额外工作，但仍有上述成本。没有通过减少原有可见单位或画质制造提升。

```sh
node --expose-gc --import tsx scripts/art-guard-blood-benchmark.ts \
  /tmp/sketch-guard-baseline docs/art/refactor/followup/guard-blood/cpu-before.json
node --expose-gc --import tsx scripts/art-guard-blood-benchmark.ts \
  . docs/art/refactor/followup/guard-blood/cpu-after.json
```

## 验证与边界

相关测试累计 **23 文件、252 个不同测试通过**：主回归 22 文件 250 测试，加表面解析测试 1 个、无武器范围测试 1 个；最终范围检查重跑 34 测试通过。TypeScript 检查通过，生产构建通过（保留已有大包提示）。附日志；测试覆盖方向计时、暂停、跨 tick 命中、接触挂点、装备更换、淡出、额外渲染频率一致及模拟状态不变。

身体采用少量近似胶囊体，武器采用实际绘制线段；不宣称完整流体或逐像素皮肤变形。快速接收者在两个快照之间的轨迹仍是近似；身体印记随整体位置/朝向而非每个肢体关节变形。现有环境只有软件 GPU，硬件 GPU 大场面帧时间和整体美术审美仍待验收。这是本轮功能与修复交付，不代表全体美术重构和性能目标已全部达成。
