# 冲锋速度线与受击血迹

本阶段是用户追加的表现需求，不改变伤害、命中、施法、随机数或 AI 决策。它在规则版本 2 分支实施；不能用此前冻结美术提交的性能数据代表新增效果的最终成本。

## 事件与表现职责

既有 hit 事件携带当次实际伤害、命中后的生命、目标类别和体型，以及可用的攻击来源位置。判断条件是非机械单位，且命中致死或剩余生命不超过本次实际伤害的两倍；不是按一帧结束时的目标生命反推每一击。投射物使用发射位置，避免射手移动后改变已命中血滴的方向。

`CombatPresentationTracker` 在客户端按事件 ID 与事件 tick 确定粒子参数，不读取或推进模拟 RNG。血量相对最大生命的比例控制数量、大小和散射速度。水平速度与重力解析出落点，地面痕迹不再追随目标；附体痕迹保持身体局部坐标并随朝向镜像。输出供 Canvas 与 GPU 消费，不为每种血迹重新生成单位贴图。

速度线只跟随实际冲锋或足够快的受迫位移，普通行走、瞬移和仅由船携带的移动不触发。甲板上的相对运动按船朝向变换。减弱动态设置关闭速度线。

## 生命周期与预算

- 活跃受击事件最多 48 个，每次最多 10 滴；额外保留 96 组落地残留。
- 空中血滴最多 480，附体标记最多 48，地面血滴最多 1440，速度线最多 128。
- 地面痕迹在 5～9 秒间褪去，附体痕迹在 3～6 秒间褪去；死亡后不把活体局部坐标强行套到尸体。
- 暂停不推进动画，后退 seek 和场景重置清空状态；超过预算时有限淘汰，密集战斗中的残留可能短于正常寿命。
- 甲板血迹在船的局部坐标中运动和落地，随宿主移动、转向；越过船边的滴不继续画到海面，沉船后清除。这里没有实现入水飞溅或流体模拟。

## 渲染与遮挡

陆地残留在 Canvas 地面层绘制，位于人物与建筑下面。WebGL 路径的甲板残留、附体血迹、空中血滴和速度线进入 `CombatInk`：一个透明实例批次，使用现有场景深度测试，不写入深度、不投影、不参与点选，也不读取 GPU 像素来做逐滴射线检测。程序化墨迹材质不新增人物纹理。Canvas 回退使用同一份表现帧直接绘制。

这些是可控的二维弹道和贴附效果，不是完整流体仿真。实际场景验证已记录在 [表现验证](combat-presentation-validation.md)：深度遮挡开启时墙后目标的血迹覆盖为 0 像素，关闭深度测试的负对照为 71 像素；6 处甲板落痕随转向移动并在沉船后清除。录像见 `after/combat-effects-proof.mp4`。这只证明功能和遮挡，新增效果的最终性能成本仍需独立测量。
