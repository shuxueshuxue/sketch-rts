# 进度显示规范

适用范围：对局里所有"还要多久""做到哪了""还剩多少"的显示，包括 HUD 的指令卡、物品栏、选中卡片、状态徽章，世界里画在建筑和单位旁边的条，以及鼠标提示里的时间。

配套文件：[作画规范](prop-painting.zh.md)（色板、线宽）、[渲染契约](render-contract.zh.md)（世界里的叠加层画在什么位置）。

现状盘点见文末附录：一共 24 处显示，用了 13 种画法、4 种秒数格式。

## 1. 四种进度，各用一种画法

每一处进度先问：它是哪一种？种类决定画法，和它出现在哪个系统里无关。

| 种类 | 含义 | 例子 | 画法 | 方向 |
|---|---|---|---|---|
| **冷却** | 还要等多久才能再用 | 技能冷却、物品冷却、雇佣兵营地补兵、商店补货、跳板冷却 | 按钮上一块暗色扇形遮罩，中间写剩余时间 | 暗扇形从 12 点钟方向开始、**顺时针缩小**；亮出来的部分顺时针变大，转满一圈即可用 |
| **工作** | 一件事做到哪了 | 训练、研究、建筑升级（含加固塔）、施工 | 一条细进度条，旁边写剩余时间 | **从左往右变长**，从空到满 |
| **存量** | 还剩多少 | 血量、护甲耐久、金矿存量、商店库存 | 从左边起的条，或者数字 | **从右往左变短**，从满到空 |
| **持续** | 效果还能维持多久 | buff、debuff、召唤物存在时间 | 图标块底部一条时间带；世界里的图标在最后 1 秒淡出 | 数字倒数 |

几条通用规则：

- 冷却从来不用"条"，工作从来不用"扇形"。玩家一眼看形状，就知道是"等"还是"在做"。
- 同一件事，HUD 和世界里用同一种颜色、同一个方向。
- 进度永远要能读出剩余时间，不只给百分比：工作显示剩余秒数；冷却和持续显示剩余秒数。百分比只出现在鼠标提示里。

## 2. 颜色

| 用途 | 颜色 | 说明 |
|---|---|---|
| 工作进度的填充 | `#7fb0d6`（冷蓝） | HUD 按钮底条和世界里的建筑进度条都用这一个颜色。现在 HUD 用绿 `#91b76f`、世界用深蓝 `#315f87`，统一成这个 |
| 工作完成、等待下一步（例如待下水） | `#d1b782`（黄铜，`--battle-accent`） | 整条变成黄铜色 |
| 冷却遮罩 | `#101c24b3`（不透明度约 70% 的深墨色） | 只盖住还没转过的那一块扇形；扇形边上一条 1px 的亮线 `#fff3d166`，标出指针位置 |
| 存量：血量和耐久 | `>50% #90b781`，`>25% #e5b45f`，否则 `#dc735c` | 和现在的血条阈值一致。耐久也改用这三档（现在是自己的一套绿和橙） |
| 增益 / 减益 | 边框 `#74a77a` / `#c97b6d` | 保持现状 |
| 进度条底槽 | `#0d161c`（HUD），`rgba(35,49,38,.28)`（世界） | 世界里的底槽加深一点，在草地和沙地上都能看清 |

蓝色只用来表示"工作"，绿、黄、红只用来表示"存量"。两组颜色不混用。

## 3. 时间格式（全局唯一）

所有显示剩余时间的地方，都用同一个函数 `formatRemaining(ticks)`：

| 剩余时间 | 显示 | 例子 |
|---|---|---|
| ≥ 60 秒 | `分:秒` | `1:05` |
| 3 秒到 60 秒 | 向上取整的整秒 | `12s` |
| 不到 3 秒 | 十分之一秒，向上取整 | `2.4s` |
| 0 | 不显示 | |

取整的顺序：先按显示精度向上取整，再决定落在哪一档。所以 2.99 秒显示为 `3s`，而不是 `3.0s`；59.9 秒显示为 `1:00`，而不是 `60s`。实现放在 `src/client/format-remaining.ts`，单元测试覆盖 2.99、3.0、59.9、60 这几个边界。

- 按钮上只有 52 像素宽，所以单位用 `s`，不写"秒"。
- 鼠标提示里的句子同样用这个格式。例如"下一次招募 12s"，不再写 `12.0s`。
- 无障碍标签（aria-label）同样用这个格式，不允许出现原始 tick 数。

## 4. 各处的具体做法

### HUD 指令卡和物品栏（52×55 的按钮）

- **冷却**（技能、物品、招募、补货、跳板）：
  - 用扇形遮罩，暗的部分从 12 点开始顺时针缩小。
  - 按钮正中写剩余时间，12px，颜色 `#fff3d1`，下面加 1px 黑色阴影。
  - 去掉现在横在按钮中部的文字带和整块变暗的效果。
  - **数字的下限**：按钮短边不小于 40 CSS 像素时，才在中心写数字。字号 12px、粗细 600，加一圈 1px 的深色描边（`#101c24`）。按钮比 40 小时，只画扇形，剩余时间放进鼠标提示。现在的指令卡按钮（52×55）和物品格都达到这个下限。
  - 技能、物品、招募、补货、跳板这五处全部一样。
  - 还在冷却的按钮不再整体降低不透明度，扇形本身已经说明它"现在不能用"。
- **工作**（训练、研究、升级、加固）：
  - 按钮底部一条 4px 的蓝条，从左往右变长。
  - 左上角徽章写剩余时间，例如 `8s`；排队中的写"排队"；等待下水的写"待下水"，同时整条变成黄铜色。
  - 百分比移到鼠标提示里：`64% · 还剩 8s`。
- **存量**：商店的货品按钮在右下角显示当前库存 `×3`。补货中的那一格同时显示冷却扇形。

### 选中卡片

- 血条保持现状：17px，中间写 `hp / max`，颜色按存量的三档。
- **新增**：选中的是施工中的建筑时，血条下面加一条 4px 的蓝色工作条，右侧写剩余时间。现在施工中的建筑在 HUD 里看不出进度。
- 选中营地时，"下一次招募"改成通用时间格式，并加同样的冷却扇形小图标。

### 世界里

- **工作条**：和血条同一个位置、同一个规格，画在建筑头顶。宽度与血条相同（建筑 48），底槽高 5、填充高 3，蓝色 `#7fb0d6`，从左往右。施工、训练、升级、研究都画这一条（现在研究在世界里不显示，要补上）。剩余时间写在条的右侧（9px），队列超过一项时，后面加 `×3`。
- **堆叠顺序**：血条和工作条同时出现时，血条在上，工作条紧贴在血条下方，间隔 2 像素，两条左对齐，互不遮挡。只有工作条时，它占血条的位置。
- **冷却**：营地的招募冷却改用世界里的小扇形（直径 12），画在库存数字左边，不再用工作条。按规则，冷却不画成条。
- **血条**：保持现状，规格不变。
- **状态图标**：保持在最后 1 秒淡出。

### 状态徽章（持续）

- 保持现状：底部时间带。时间改用通用格式（现在的规则本来就是这个格式的来源）。

## 5. 不做的

- 不给修理加进度显示。修理过程中血条在涨，那就是它的进度，属于"存量"。
- 不给船炮装填加 HUD 显示。后坐动画已经说明了状态。
- 不给采矿加进度条。工人手上的金块已经说明了状态。
