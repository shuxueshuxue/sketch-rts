# Sketch RTS

一款以物理陆海作战为核心的浏览器即时战略游戏。发展经济，指挥混合军队，让船只成为带有真实船员、货物与武器的作战平台。

[在线游玩](https://lexicalmathical.com/sketch-rts/) · [English](../README.md) · [开发指南](development.md)

![六种当前船体的不同帆装与甲板布局](art/readme-ship-lineup.gif)

## 游戏特色

- **移动影响战斗。** 远程单位先瞄准再开火，移动超出瞄准容许范围就会失去准备。骑兵、近战和远程部队各有接敌方式，也可以预备瞄准一个地点来布置伏击。
- **船员真正站在甲板上。** 人员占用甲板空间，船与船、船与岸接触后可以通行。把火炮装到兼容炮位，转出舷侧齐射，用农民修复受损部件，或主动部署短桥、登舰争夺敌船。步行船员可进入避险舱，暂停攻击与施法；舱容按人口和体型分配，界面显示已用舱容与选中所需空间。快艇自带弓箭攻击，与安装的舰炮独立工作。
- **物品有实际位置。** 人物有头、身体、脚三个穿戴位，手上与背上共用四个携行位。船舱运输物资与重型武器，商店可把商品直接交给指定的附近人物或船只。
- **经济与地形塑造对局。** 林地族和灰烬族有不同兵种与科技。争夺金矿、野怪营地和雇佣兵据点，在群岛、河湾与林地间扩张作战。地图池包含 2、4、6、8 人图，以可复现的生成布局和生态环境场构造地形。
- **玩家与程序共用游戏。** 支持单人和多人对局，可选择 V9 弓手、召唤或骑兵对手，也可以用 TypeScript SDK 编写控制器。指令、回放和 AI 基准测试运行同一套模拟。

项目持续开发中，界面支持中文和英文；游玩需要电脑、键盘和鼠标。船只与建筑使用实时三维模型，人物保留插画卡片，地形与界面叠层由 Canvas 绘制；没有 WebGL2 时使用 Canvas 回退。

## 开始游戏

1. 打开[在线游戏](https://lexicalmathical.com/sketch-rts/)，先选地图，再配置对局。
2. 设置队伍、种族和玩家席位。选择具体种族后可以指定 AI 版本；随机种族使用随机的兼容 AI。
3. 创建房间，邀请朋友加入，真人玩家准备好后开始比赛。

地址栏本身就是分享链接：创建前的配置 URL 包含所选地图和席位设置，创建后的房间 URL 标识该房间。分享你希望对方打开的那个阶段的地址即可。

![在线界面中选择地图并配置八人对局](art/readme-match-setup.gif)

选中农民，右键金矿开始采金。建造基地、训练军队，悬浮查看指令的价格、条件和快捷键。选中船只，打开「船舱 / 配置」可调整船员位置、货物和武器。

| 操作 | 作用 |
| --- | --- |
| 左键单击 / 拖动 | 单选 / 框选 |
| 右键 | 移动或与目标交互 |
| `A` 后点击 | 攻击移动 |
| `Shift` + 命令 | 排队执行 |
| `Shift` + `1`–`9` / `1`–`9` | 设置 / 调用编队 |
| `Tab` | 切换当前兵种 |
| `B` | 打开农民的建造菜单 |
| `I` | 打开人物装备或船舱与炮位配置 |
| `J` 后点击 | 让支持瞄准的远程单位预备瞄准地点 |
| 方向键 / 屏幕边缘 / 小地图 | 移动镜头 |
| `Esc` | 取消目标选择、关闭面板或释放鼠标 |

## 本地运行

需要 **Node.js 20.19+ 或 22.12+** 和 npm。

```bash
git clone https://github.com/shuxueshuxue/sketch-rts.git
cd sketch-rts
npm ci
npm run dev
```

打开 [localhost:5173](http://localhost:5173/)。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 带房间与 SDK 接口的游戏服务器 |
| `npm run dev:static` | 无需后端的本地浏览器游戏 |
| `npm test -- --run` | 运行测试 |
| `npm run build:production` | 构建客户端与服务器 |
| `npm run record -- --list` | 列出可复现的录制场景 |
