# V5 / V7 / V8 实战行为改进

目标是让对局中的决定更合理，保留 V5 的远程核心、V7 的多种发展路线、V8 的近战与治疗配合。
评估关注机会、阵形、支援与撤退，不以胜率或榜单成绩作为优化目标。

## 本轮修复

| 实战问题 | 当前处理 |
| --- | --- |
| 同一轮移动指令挡掉冲锋，或覆盖走过去施法的指令 | 冲锋先于普通调动；冲锋和需要接近目标的施法保留指令占用，即时治疗仍可与移动并行 |
| 一整队近战挤向同一个远程目标 | 集火只接纳已经接触目标的近战；步兵沿自己的接敌面作战 |
| 骑士追前排，放过暴露的攻城车和法师 | 机动近战优先切暴露的远程武器和施法者；遇到强近战屏障或新的塔火覆盖时停止单独深入 |
| TR 的建塔工人在眼前，却没人打 | 基地附近的建塔工人进入高优先级拦截目标 |
| V7 把自己的前进误判成敌军增援 | 使用敌军位置变化判断接近；V7、V8 都保存敌军上次位置 |
| 敌军已崩溃，仍机械等待固定大军门槛 | 有当地兵力优势时，小军队也可惩罚暴露的主基地 |
| 新基地还没完工，援军守在旧基地 | 防守位置包含正在建造且受袭的城镇大厅 |
| 回防已经来不及，仍放弃眼前即将攻破的敌基地 | 仅在另有安全基地、当地战斗有利且敌大厅残血时继续换家；否则按原防守逻辑处理 |
| 盟军受袭，附近可用部队和治疗者没有反应 | 根据道路距离、到达时间、盟军守军和敌军强度决定救援；自家遭遇进攻时释放救援任务，治疗可用于盟军 |
| 海外殖民地让主军误以为可以步行前往敌岛 | 主军情报与兵力限于自己的陆地连通区域，岛上的战线由海军模块管理 |
| 登陆目标消失，船上的人被永久留在船舱 | 取消任务后停止未完成的登船，载人返回出发岸并卸载 |
| 明知岸边无法打赢，仍继续送小队登陆 | 航行时重新评估登陆点；威胁突然增强时撤回 |
| 明明海岸可以登陆，却被内陆守军吓住 | 抢滩评估岸边实际威胁，再由登陆部队集结推进 |
| 全军够打，只有一艘满船，长期停在岸边 | 需要同时运输更多部队时追加运输容量，能解锁大型运输船时优先使用 |
| 岛上小队和工程师明显守不住，却没有撤离任务 | 空运输船可以接走孤立的弱势小队，送往安全的现有基地 |

支援、登船和岛上战线都有明确的部队归属。脚本按优先顺序认领部队，后面的主军或微操模块不能抢走
已经交给运输或救援任务的部队。

## 射程调整

所有远程兵种的基础攻击射程缩短 20%，包括远程雇佣兵、远程中立兵、舰炮和攻城远程武器。
弩炮钉射、炮击、霰弹与燃烧弹等远程武器技能同步缩短。近战基础射程、防御建筑射程、冲锋窗口和
治疗、召唤、诅咒等法术距离保留。

缩短后只有 88 射程的树皮治疗者仍按远程弹道和重甲减伤结算。射程科技不会把近战武器变成远程弹道。
其他价格、生命、伤害和训练时间本轮没有调整。

## 验证

- 完整测试：221 个文件、1786 条检查通过，其中新增 55 条检查覆盖指令占用、盟军救援与治疗、目标选择、
  TR 拦截、换家、殖民地战线归属、运输取消与撤离、运力和全部远程基础射程。
- `npm run build:production` 通过，包含 TypeScript 检查、客户端构建与服务器打包。
- 五组自然对局均使用正常运行时和共享模拟，指令错误为零。对局观察上限为 24000 tick（20 分钟）。

| 观察场景 | 当前结果 |
| --- | --- |
| pineshade：V5 / V7 单挑 | 21574 tick 结束，出现 243 次近战目标分配 |
| elderwood：V8 / V5 对 V7 / V8 的团队局 | 15172 tick 结束，出现盟军支援与冲锋 |
| 新种子的三方陆地局 | 20 分钟仍在继续，出现进攻、防守、清营地与近战目标选择 |
| brokenSea 四方海战 | 20 分钟仍在继续，出现登陆、搬迁与弱势岛上撤离 |
| 新种子的海岛单挑 | 16142 tick 结束；此前同种子在 20 分钟时双方仍有大批闲置陆军和满载等候的运输船 |

前后观察同时包含 AI 修复与射程调整，用于发现行为问题，不用于推导胜率或单项修复的强度收益。
未结束的对局保留在报告中。

复现自然观察：

```bash
node --import tsx scripts/ai-behavior-playtest.ts --ticks=24000 --output=/tmp/ai-behavior.json
node --import tsx scripts/ai-behavior-playtest.ts --case=unseen-islands --output=/tmp/ai-islands.json
```

报告记录调动、交战、闲置、主军模式、运输阶段、船舱与指令错误。测试地图和种子只存在于观察脚本，
不会进入 AI 决策。

## 仍需继续观察

这是一轮有明确复现和回归的修复，不能据此宣称所有不合理行为都已消失。长海战仍可能持续超过观察上限。
跨海盟军救援尚未整合成联合舰队任务；当前盟军支援处理可步行到达的战线。换家判断要求另有安全基地，
失去全部大厅后仅靠残余工人和运输船重建的复杂情况也需要独立实战验证。
