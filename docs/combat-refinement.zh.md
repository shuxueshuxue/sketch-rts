# 建筑重设计与战斗画面减法

基于 Painted Frontier 继续修改。全部 14 种可建造建筑替换为新设计，复用几何投影管线，不复用上一版房屋组合。

- 城镇中心：八角议事主楼、侧翼、入口廊与石质基座。
- 兵营：围合操练场、带垛口的双塔门；靶场：开放棚架与三只圆靶；马厩：长条开放马栏与围场。
- 农场：风车粮仓和田垄；工坊：作业棚与大型木轮；船厂：船肋、船台和吊架。
- 圣所：穹顶与石质扶壁；防御塔：木制瞭望平台；月井：水池与高低石柱。
- 灰烬熔炉、尖塔、神殿和大厅：玄武岩、铜色构件、炉体与尖冠轮廓。

建筑增加依据底部几何计算的接触阴影、土边与墙脚暗边，减轻悬浮感；修复同一平面深度的浮点误差导致水面被底座覆盖的问题。复杂构件仍采用近似面排序，不是完整深度缓冲渲染器。

人物修正：骑枪以握点整体旋转，固定长度，短幅前送回收，去掉枪尖旗片。农民补脖颈，工具置于头部轮廓之外。保留既有整体人物风格。

战斗减法：去掉近战双方之间的黑线；命中红十字换成短暂的小闪点；攻击指令标记改成固定小环；冲锋速度线从多条减为一条并降低透明度，冲锋火花数量减少。保留箭矢、技能效果与操作确认。受击抖动系数从 26 降至 7，最大位移从 12 降至 2，并加入平方衰减，不改变结算。

预览在 `art/combat-refinement/`：`buildings.png` 是全部建筑，`details.gif` 展示农民与骑士动作和主楼，`match.png` 是实际浏览器战场。`before-combat.gif` / `after-combat.gif` 使用同一 cavalry-charge 场景、同一镜头、10 秒真实模拟，可比较战斗标记与抖动。

复现：

```sh
node --import tsx scripts/render-building-review.ts
node --import tsx scripts/render-combat-refinement.ts
node --import tsx src/recorder/cli.ts --scene cavalry-charge --seconds 10 --size 1280x720 --camera 1950,2048,1.1 --out docs/art/combat-refinement/after-combat.gif --gif-size 960x540 --fps 20
```

验证：静态构建通过，54 个测试文件、251 项测试通过；包含人物所有动作与方向及全部建筑的 atlas 边界检查。最终遮挡调整后再次完成构建和边界测试。浏览器中文战场及建造栏检查无页面异常。既有大包警告仍在。
